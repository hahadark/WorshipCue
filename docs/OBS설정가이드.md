# OBS 설정 가이드

WorshipCue 는 이 PC 안에서만 동작하는 웹 서버(127.0.0.1)를 열고, OBS 는 그 화면을 **브라우저 소스**로 받아 표시합니다.
성경 본문·찬양 가사·찬송가 악보·광고·영상 등 송출하는 화면이 바뀌면 OBS 화면도 즉시 바뀌며, 새로 고침이나 재등록이 필요 없습니다.

## 주소

| 용도 | 주소 | 기본 템플릿 |
|---|---|---|
| 전체 화면 (예배당과 같은 디자인) | `http://127.0.0.1:37528/outputs/main` | 일반 예배 |
| 투명 자막 (영상 위 합성) | `http://127.0.0.1:37528/outputs/overlay` | 투명 출력 |
| 무대 화면 (설교자·찬양팀 모니터) | `http://127.0.0.1:37528/outputs/stage` | 지금·다음 슬라이드, 시계, 타이머 |

- 포트(37528)는 설정 → 출력에서 바꿀 수 있습니다. 바꾸면 프로그램을 다시 시작하고 OBS 주소도 바꿔야 합니다.
- 실제 주소는 **설정 → 출력**에 표시되며 "복사" 버튼으로 복사할 수 있습니다.

## 추가 방법

1. OBS → 장면 선택 → 소스 `+` → **브라우저**
2. 이름: `WorshipCue 자막` (자유)
3. 설정
   - **URL**: `http://127.0.0.1:37528/outputs/overlay`
   - **너비 / 높이**: `1920` / `1080` (템플릿 해상도와 같게. 4K 템플릿이면 3840 / 2160)
   - **사용자 지정 CSS**: 비워 두세요 (OBS 기본값의 `background-color: rgba(0,0,0,0)` 그대로 두어도 됩니다)
   - **"소스가 보이지 않을 때 종료"**: 끄기 (켜면 장면 전환 때마다 다시 연결됩니다. 다시 연결되어도 최신 화면을 받지만 끄는 것을 권장)
   - **"장면이 활성화될 때 브라우저 새로 고침"**: 끄기
4. 확인 → 소스를 화면 전체 크기로 맞춥니다 (`Ctrl+F` 화면에 맞추기).

전체 화면 출력도 같은 방법으로 `/outputs/main` 을 추가합니다.

## 동작

- 송출(F9 · 더블클릭 · F6)하면 OBS 화면이 바로 바뀝니다. 전환은 디졸브·컷 중에서 출력마다 고릅니다 (빠른 설정 → 전환).
- 찬송가·찬양 PPT 는 투명 자막(`/outputs/overlay`)에 **가사 글자만** 나갑니다 (빠른 설정 → `PPT 슬라이드: 가사만`).
- 영상 순서의 **소리는 예배당 화면 창에서만** 납니다. OBS 브라우저 소스는 소리 없이 화면만 맞춰 재생하므로, 방송에 소리를 넣으려면 OBS 에서 PC 소리(데스크톱 오디오)를 잡으세요.
- 슬라이드 편집으로 꾸민 위치·꾸미기는 투명 자막에는 기본으로 적용하지 않습니다 (편집기의 'OBS 자막에도 적용').
- F10(글자 숨김)을 누르면 투명 자막은 완전히 투명해집니다. 다른 영상 요소에는 영향이 없습니다. 배경·오버레이·로고 화면은 하단 지우기 단추로 따로 지웁니다.
- WorshipCue 를 재시작해도 같은 주소를 사용합니다.
- 연결이 끊기면 마지막 화면을 유지한 채 1초 간격으로 자동 재연결하고, 연결되면 최신 송출 상태를 다시 받습니다.

## 연결 확인

WorshipCue 하단 오른쪽:
- `OBS 자막 1개 동기화됨` (초록): OBS 가 최신 송출 내용을 받아 표시했다고 응답한 상태
- `갱신 대기` (노랑): 상태를 아직 받지 못함(잠시 뒤에도 계속이면 OBS 소스 확인)
- `연결 없음` (회색): 그 주소로 연결된 OBS 소스가 없음

설정 → 출력 → "출력 연결 상태"에서 연결별 화면 크기와 수신 버전을 볼 수 있습니다.

## 디자인 바꾸기

설정 → 템플릿에서 "투명 출력 (OBS 자막)" 또는 "설교 송출 (하단 자막)"을 편집하거나 복제해 교회 디자인으로 저장한 뒤,
설정 → 출력 → **OBS 투명 자막** 칸에서 그 템플릿을 지정합니다. 저장 즉시 OBS 화면에 반영됩니다.

- 하단 자막 위치: 템플릿의 "세로 배치 = 아래"와 "여백 아래/위"로 조정
- 자막 뒤 반투명 상자: "본문 뒤 상자"
- 밝은 배경 영상에서 잘 보이게: "외곽선 두께" 2~3px, "그림자"

## 보안

- 서버는 127.0.0.1(이 PC)에서만 요청을 받습니다. 다른 PC나 인터넷에서는 접속할 수 없습니다 (무대 화면 주소도 마찬가지).
- 휴대폰 리모컨만 따로 켜는 작은 서버(같은 Wi-Fi, PIN 필요)로 열립니다. 리모컨을 끄면 그 서버도 닫힙니다.
- 조작 명령은 WorshipCue 화면에서만 보낼 수 있고, 일반 웹사이트가 이 PC의 WorshipCue 를 조작하는 것은 차단됩니다.
