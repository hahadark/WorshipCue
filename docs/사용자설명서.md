# WorshipCue 사용자 설명서

교회 방송실에서 성경구절을 찾아 예배당 화면과 OBS 방송에 송출하는 프로그램입니다.
**검색·미리보기는 송출 화면을 절대 바꾸지 않습니다.** 송출 명령(F9, Ctrl+Enter)을 실행했을 때만 Live 화면이 바뀝니다.

---

## 1. 처음 준비

1. WorshipCue 를 실행합니다.
2. **설정 → 성경 데이터**에서 성경 파일을 가져옵니다.
   - 지원 형식: JSON, CSV(책,장,절,본문), Zefania XML
   - 파일을 고르면 검증 보고서(오류·경고·인코딩)가 나옵니다. 오류가 있으면 가져올 수 없고, 기존 데이터는 바뀌지 않습니다.
   - 번역본 ID·이름·**사용 허가 정보·출처**를 입력해야 가져올 수 있습니다.
   - 개역개정·새번역 등 보호 대상 번역본은 권리자의 허가를 받은 뒤 사용하세요.
3. **설정 → 출력**에서 예배당 모니터를 고르고 "전체 화면 출력 켜기"를 체크합니다.
4. OBS 를 쓰면 [OBS 설정 가이드](OBS설정가이드.md)를 따라 브라우저 소스를 추가합니다.

> 인터넷 연결은 필요 없습니다. 모든 검색과 출력은 이 PC 안에서 처리됩니다.

## 2. 화면 구성

| 위치 | 내용 |
|---|---|
| 맨 위 | 메뉴바 (파일 · 편집 · 순서 넣기 · 송출 · 보기 · 작업공간 · 도구 · 리모컨 · 설정 · 도움말) |
| 상단 | 검색창, 검색 방식(자동/장절/본문), 번역본, 미리보기 켜기·끄기, **작업공간** 선택칸, ⚙ 설정 |
| 왼쪽 | **큐시트**(예배 순서) / 성경 66권 목록 탭 |
| 가운데 | 큐시트 순서를 고르면 위쪽에 **편집칸**(입력 즉시 자동 저장), 아래에 슬라이드 목록. 성경 검색 시 찾은 본문(절 목록) 또는 본문 검색 결과. 초록 줄 = 미리보기 중인 절, 빨간 줄 = 송출 중인 절 |
| 오른쪽 위 | **미리보기** (초록 테두리) — 송출하면 이렇게 나갑니다 |
| 오른쪽 아래 | **LIVE** (빨간 테두리) — 지금 실제로 나가고 있는 화면. 숨김 중이면 점선 테두리와 "숨김 중" 표시 |
| 하단 | 이전·다음·송출 / 지우기 단추 묶음(글자·배경·오버레이·음악·로고·모두), 보조 화면, 출력 연결 상태 |

미리보기·LIVE 오른쪽의 **예배당 / OBS** 버튼으로 각 출력 디자인을 확인할 수 있습니다.

## 2-B. 주보로 큐시트 만들기 (AI)

창 위쪽에서 방법을 고릅니다. API 키가 없으면 '채팅 AI로' 가 먼저 열립니다.

### 채팅 AI로 (키 없이)

이미 쓰는 ChatGPT · Claude · Gemini 같은 채팅 AI 로 만듭니다. 요금·키가 필요 없습니다.

1. (선택) '추가 요청' 에 원하는 것을 적습니다 (예: 오후 예배 순서로).
2. `📋 프롬프트 복사` 를 누르고, `💾 샘플 파일 저장` 으로 `WorshipCue-큐시트-샘플.json` 을 받습니다.
3. `ChatGPT 열기` 등으로 채팅 AI 를 열고, **주보(PDF 나 사진)** 와 샘플 파일을 올린 뒤 프롬프트를 붙여 넣어(Ctrl+V) 보냅니다.
   - hwp 는 채팅 AI 가 잘 못 읽으니 한글에서 'PDF로 저장' 하거나 화면을 캡처해 올리세요.
   - 샘플 파일을 못 올려도 프롬프트에 형식이 들어 있어 됩니다.
4. AI 의 답을 통째로 복사해 3번 칸에 붙여 넣고 `✓ 큐시트 만들기`. AI 가 `WorshipCue-큐시트.json` 같은 파일을 만들어 줬다면 `📂 결과 파일 불러오기` 나 창에 끌어다 놓기.
5. 결과 목록과 '확인할 것' 을 보고 `이 큐시트 열기`.
   - '답에서 큐시트 JSON 을 찾지 못했습니다' 가 나오면 AI 에게 "JSON 코드 블록 하나로 다시 답해 줘" 라고 하세요.

### API 키로 (자동)

1. `파일 → 🤖 주보로 큐시트 만들기` (또는 큐시트 `⋯` 메뉴).
2. 처음 한 번 **오픈라우터 키**를 넣고 `저장` 합니다. (`키 발급…` 단추로 openrouter.ai 키 페이지가 열립니다. 키는 이 PC 에만 암호화해 저장됩니다.)
3. AI 모델은 기본값(Claude Haiku 5.5)을 권합니다. PDF·사진 주보는 Gemini Flash 가 더 잘 읽습니다.
4. `📄 주보 파일 고르기…` 로 hwp·hwpx·docx·pdf·사진·txt 를 고르거나, 예배 순서 부분을 글로 붙여 넣습니다. 필요하면 '추가 요청'(예: 오후 예배 순서로)을 적습니다.
5. `🤖 큐시트 만들기` → 10~30초 뒤 결과 목록이 나옵니다. `이 큐시트 열기` 로 엽니다.
6. 찬송가는 등록한 찬송가 PPT 와 자동 연결되고, 장절은 성경 DB 로 확인됩니다. '확인할 것' 이 나오면 그 순서를 직접 고치세요. AI 결과이니 송출 전에 한 번 훑어보세요.

## 2-C. 예배 진행 시계

- 큐시트 위 ⏰ 칸에 예배 시작 시각(예: 11:00)을 넣고, 순서 편집칸의 **예정 시간**에 분을 넣습니다.
- 순서마다 오른쪽에 예정 시작 시각이 나오고, 위쪽에 '끝 예정', 송출 중에는 '지금 5번 · 예정 11:12 · 3분 늦음'(빨강) / 이름(파랑) / 제시간(초록)이 보입니다.
- 실제로 각 순서를 송출한 시각은 이 PC 에 기억됩니다.

## 2-D. 찬양: 부를 순서와 바로 가기 키

- 가사에 `[1절]` `[2절]` `[후렴]` 을 한 번씩만 쓰고, 편집칸 **부를 순서**에 `1절 후렴 2절 후렴 후렴` 처럼 적습니다. 아래 이름표 단추를 누르면 순서 끝에 붙습니다. 줄여서 `1 C 2 C C` 도 됩니다. 라이브러리 찬양에도 기본 부를 순서를 저장할 수 있습니다.
- 찬양을 송출 중일 때 키보드 `1`~`9` = 그 절, `C` = 다음 후렴, `B` = 브릿지, `E` = 엔딩. LIVE 아래에 '⌨ 1~9·C·B' 가 보이면 쓸 수 있습니다. 찬양팀이 즉흥으로 후렴을 반복할 때 `C` 만 누르면 됩니다.

## 2-E. 슬라이드 격자 · 통합 검색

- 가운데 위 `목록 | 격자` 로 바꾸면 슬라이드가 실제 화면 모양 썸네일로 보입니다. 클릭 = 미리보기, 더블클릭 = 송출, 화살표로 이동, 슬라이더로 크기 조절.
- 위 검색창은 성경뿐 아니라 라이브러리의 찬양·찬송가·이미지·영상·음악도 찾습니다. 아래쪽 '라이브러리' 결과를 고르면 큐시트의 고른 순서 다음에 들어갑니다.

## 2-F. 무대 화면 · 설교 타이머 · 휴대폰 리모컨

- '무대·타이머' 패널(또는 `도구` 메뉴)에서 `🖥 무대 화면 창 열기` → 설교자 모니터로 끌어다 놓습니다. 같은 주소를 다른 PC·태블릿 브라우저나 OBS 에서 열어도 됩니다.
- 설교 타이머: 5~40분 단추 또는 직접 입력 → 시작. 일시정지·계속·±1분·지우기. 5분 전에는 노란색, 시간이 지나면 빨간색으로 넘긴 시간(+02:13)을 보여 줍니다.
- 무대 메시지: 글을 쓰고 `보내기`(또는 '5분 남았습니다' 같은 빠른 단추). 무대 화면 위쪽에 깜빡이며 보입니다. `지우기` 로 내립니다.
- **휴대폰 리모컨**: 메뉴바 `리모컨 → 리모컨 열기` 에서 켜면 QR 코드·주소·PIN 이 나옵니다. 휴대폰 카메라로 QR 을 찍으면 바로 열립니다. 같은 Wi-Fi 의 휴대폰 브라우저에서 주소를 열고 PIN 을 넣으면 이전·다음·숨김, 절·후렴 바로 가기, 큐시트 순서 송출, 무대 메시지·타이머를 쓸 수 있습니다. 처음 켤 때 Windows 방화벽 창이 뜨면 '개인 네트워크' 를 허용하세요.

## 2-G. 화면 지우기 단추

아래 단추줄: `글자 숨김(F10)` · `배경 지우기`(배경 이미지·영상 숨김) · `오버레이 끄기`(다시 누르면 켜져 있던 것만 다시) · `음악 멈춤`(2.5초 페이드) · `로고 화면`(검은 바탕 가운데 로고) · `모두 지우기`. 켜진 상태의 단추는 노란색입니다.

## 2-I. 슬라이드 편집 (FreeShow 방식)

찬양·공지·제목 순서의 슬라이드를 하나하나 꾸밉니다.

- 열기: 순서 편집칸 `✏ 슬라이드 편집` · 슬라이드 격자 썸네일의 ✏ 또는 오른쪽 클릭 · 슬라이드 목록 오른쪽 클릭 · `편집 → 슬라이드 편집` · **Ctrl+E**
- 왼쪽 목록: 맨 위 **공통**(모든 슬라이드), 그 아래 가사·글 덩어리마다 슬라이드. 따로 꾸민 슬라이드에는 노란 점.
- 가운데 캔버스: 글상자를 끌어 옮기기, 모서리·변의 흰 점으로 크기 조절. 가운데선·가장자리에 붙고(분홍 선), Alt 를 누르면 안 붙습니다. Shift = 비율 유지.
- **더블클릭** 또는 Enter: 화면에서 바로 글 고치기 (Ctrl+Enter 또는 바깥 클릭 = 적용, Esc = 취소). 고친 글은 순서의 가사·공지 내용에 그대로 들어가고, 라이브러리 찬양이면 라이브러리에도 저장됩니다.
- 오른쪽: 글자 크기(넘치면 줄이기), 색·굵게·기울임·그림자, 가로·세로 정렬, 줄 간격, 색 상자(투명도·모서리), 위치·크기(%). '템플릿 위치로' · '꾸미기 초기화'.
- 슬라이드 배경: 그림·영상·색. '본문 글 숨기기' (덧붙인 것만 보이게).
- 덧붙이기: `＋ 글상자` `＋ 그림` `＋ 도형`. '본문 글 뒤로/앞으로', 복제(Ctrl+D), 지우기(Delete).
- '이 꾸미기를 모든 슬라이드에' = 이 슬라이드의 위치·꾸미기를 공통으로. '이 슬라이드 초기화' = 따로 꾸민 것 지우기.
- 위쪽 `예배당 | OBS 자막` 으로 출력별 모양을 보며 고칩니다. OBS 자막(투명 배경)에는 글 내용만 반영되고, 'OBS 자막(투명)에도 위치·꾸미기 적용' 을 켜면 모두 반영됩니다.
- 되돌리기 Ctrl+Z · 다시 Ctrl+Y · 슬라이드 넘기기 PageUp/PageDown · 닫기 Esc 또는 `완료`. 편집기가 열려 있어도 F5·F6·F9·F10 송출 키는 그대로 됩니다.
- 편집 내용은 큐시트 순서에 저장되므로, 큐시트를 복제하면 함께 복제됩니다. (가사 덩어리를 새로 넣거나 지우면 슬라이드 번호가 바뀌어 꾸민 것이 다른 슬라이드로 갈 수 있습니다.)

## 2-J. 파일 끌어다 놓기

탐색기에서 끌어다 놓으면 됩니다 (화면 아래에 어디에 들어가는지 안내가 나옵니다).

- 큐시트·아무 곳: PowerPoint(.ppt .pps .pptx .ppsx) → 찬송가·PPT 순서, 그림 → 이미지, 영상 → 영상, 음악 → 음악, 가사 .txt → 찬양 순서. 여러 파일을 한 번에 놓으면 차례로 들어갑니다. 큐시트의 어떤 순서 위에 놓으면 그 순서 다음에 들어갑니다.
- 순서 편집칸: 그림·영상 → 그 순서 배경
- 라이브러리 패널: 폴더 → 지금 탭의 폴더로 등록 (이미지·영상 / 음악 / 찬송가·PPT)
- 슬라이드 편집기: 그림·영상 → 놓은 자리에 덧붙이기
- AI 주보 창: 주보 파일
- 끌어다 놓은 파일은 등록 폴더 밖에 있어도 열립니다 (최근 500개 기억). 파일을 옮기거나 지우면 다시 끌어다 놓으세요.

## 2-K. 화면 테마 · 글자 크기 (조작 화면)

`보기 → 🎨 화면 테마 · 글자 크기` (또는 `설정` 메뉴). 이 조작 화면의 색과 글자 크기만 바뀝니다. 송출 화면(예배당·OBS)의 디자인은 '빠른 설정 → 테마' 에서 따로 고릅니다.

| 테마 | 언제 |
|---|---|
| 어둡게 (기본) | 어두운 방송실. 눈부시지 않게, 글자 대비를 높였습니다 |
| 고대비 | 가장 또렷하게: 검은 바탕·흰 글자·진한 테두리 (시력이 약하거나 화면이 멀 때) |
| 밝게 | 낮 예배·밝은 사무실에서 준비할 때 |
| 따뜻하게 | 푸른 빛을 줄인 갈색. 오래 볼 때 눈이 편합니다 |
| 푸른 밤 | 짙은 남색 바탕 |

- 글자 크기: 작게 · 보통 · 크게 · 아주 크게. 단축키 Ctrl+Shift+= (크게) / Ctrl+Shift+- (작게).
- 고른 테마는 설정에 저장되어 다음 실행에도 그대로입니다.

## 2-H. 작업공간 (화면 배치 저장·바꾸기)

작업공간은 패널 배치를 이름 붙여 저장해 둔 것입니다. 상황마다 바꿔 씁니다.

| 기본 제공 | 단축키 | 쓰임 |
|---|---|---|
| 기본 | Ctrl+Alt+1 | 큐시트 · 본문/편집 · 빠른 설정·라이브러리 · 미리보기·LIVE |
| 예배 준비 (편집 크게) | Ctrl+Alt+2 | 큐시트·편집칸·라이브러리를 크게, 미리보기·LIVE 는 작게 |
| 예배 중 (송출 크게) | Ctrl+Alt+3 | LIVE·미리보기를 크게, 슬라이드 격자, 아래 무대·타이머 |
| 간단 (큐시트 + LIVE) | Ctrl+Alt+4 | 노트북 등 작은 화면 |

- 바꾸기: 상단 '작업공간' 선택칸, 메뉴 `작업공간`, 또는 Ctrl+Alt+숫자.
- 저장: 패널을 원하는 대로 배치 → `작업공간 → 지금 배치를 새 작업공간으로 저장…` → 이름(예: 수요예배, 찬양팀 연습). 내 작업공간은 Ctrl+Alt+5 부터 차례로.
- 고치기: 작업공간을 연 채로 배치를 바꾼 뒤 `지금 작업공간에 배치 덮어쓰기`. 이름 바꾸기·순서(▲)·지우기는 `작업공간 관리…`.
- 기본 제공 작업공간은 덮어쓸 수 없습니다 (덮어쓰기를 누르면 새 작업공간으로 저장).

## 2-0. 화면 배치 바꾸기 · 미리보기 끄기

- 각 패널 위의 **탭을 끌어** 다른 패널의 가장자리(위·아래·왼쪽·오른쪽)에 놓으면 그쪽에 붙고, 가운데에 놓으면 탭으로 합쳐집니다. 경계선을 끌면 크기가 바뀝니다.
- 탭 줄 오른쪽 ⧉ = 떠 있는 창으로 띄우기, ⇲ = 다시 붙이기. 탭의 ✕ = 패널 닫기.
- `작업공간 → 패널 보이기·잠그기…`: 닫은 패널 다시 켜기 · **배치 잠그기**(예배 중 실수 방지) · 기본 배치로 되돌리기. 배치는 자동 저장됩니다.
- 상단 `미리보기 켜짐` 단추를 누르면 **미리보기 끔 · 바로 송출** 이 됩니다. 미리보기 패널이 닫히고, 큐시트 순서·본문·슬라이드를 클릭하면 바로 송출됩니다. 다시 누르면 미리보기 방식으로 돌아갑니다.

## 2-1. 큐시트 바로 고치기

- 왼쪽 큐시트에서 순서를 **클릭**하면 가운데 위쪽 편집칸에 그 순서의 내용이 나옵니다.
- 제목·가사·장절·내용·배경을 고치면 **바로 저장**되고 미리보기도 바로 바뀝니다 (저장 버튼 없음).
- 편집칸의 ▲ ▼ 로 순서 이동, `복제`, `지우기` 를 할 수 있습니다. 끌어서 옮겨도 됩니다.
- 아래 `🎼 찬송가 📖 성경 🎵 찬양 …` 버튼으로 넣은 새 순서는 **지금 고른 순서 바로 다음**에 들어갑니다.

## 2-2. 찬송가·찬양 PPT

1. `🎼 찬송가·PPT` 버튼 → `찬송가 폴더·기본 배경 설정` → `📁 폴더 고르기…` 로 찬송가 폴더를 등록합니다. 새찬송가·구세군 찬송가·교독문처럼 여러 폴더를 등록할 수 있습니다.
2. 검색칸에 번호(`10`)나 제목 일부를 입력하고 **Enter** 또는 **더블클릭** → 큐시트에 추가됩니다. 창이 열려 있으므로 여러 곡을 연달아 넣을 수 있습니다.
3. 악보와 배경이 분리된 파일은 배경을 고를 수 있습니다: **원래 배경 / 흰 배경 / 템플릿 배경 / 다른 이미지**.
   - 전체 기본값: 찬송가 설정 창의 `기본 배경`
   - 곡마다: 가운데 편집칸의 `배경`
4. 다른 곡으로 바꾸려면 편집칸의 `다른 찬송가로 바꾸기` 를 누릅니다.
5. 폴더마다 읽는 방식을 고를 수 있습니다: **자동**(악보·배경 나눔) / **화면 그대로**(PowerPoint 로 슬라이드를 그대로, PowerPoint 필요).

### OBS 에는 가사만 보내기

- 빠른 설정에서 `OBS 자막` 을 고르고 `PPT 슬라이드` 를 **가사만** 으로 두면, PPT·찬송가 슬라이드가 OBS 에는 하단 가사 글자로만 나갑니다. (예배당 화면은 `그림 그대로`)
- 새찬송가는 베들레헴 성경의 가사 DB(`BethlehemWin\새찬송가.hdb`)에서 가사를 가져와 악보 슬라이드에 맞춰 자동으로 나눕니다.
- 가사가 다르면 편집칸의 `OBS 가사` 에 직접 고칩니다 (`자동 가사 넣어 고치기` → 고치기).

### 전환 효과

빠른 설정 → `전환` 에서 **디졸브**(서서히 겹쳐 바뀜, 시간 조절) 또는 **컷**(바로 바뀜)을 고릅니다. 예배당 화면과 OBS 를 따로 정할 수 있습니다.

### 내 폴더에 없는 찬양: 온라인에서 찾기

1. 검색했는데 없으면 `🌐 온라인에서 '제목' 찾기` 를 누릅니다. 기본 브라우저에 검색 결과가 열립니다.
2. 브라우저에서 PPT 를 받습니다 (비밀번호가 필요한 글은 사이트 안내대로 직접 입력).
3. 프로그램이 20분 동안 다운로드 폴더를 지켜보다가, 받은 PPT 를 `문서\WorshipCue 찬양 PPT` 로 옮기고 큐시트에 자동으로 넣습니다. (노란 안내줄의 `그만` 으로 멈출 수 있습니다)
4. 검색 주소·다운로드 폴더·모으는 폴더는 `찬송가 폴더 · 기본 배경 설정` 아래 '온라인에서 찾기'에서 바꿉니다.

## 3. 기본 사용법

### 설교자가 갑자기 다른 구절을 말할 때
1. `Ctrl+K` → 검색창
2. `행5:29` 입력 → `Enter` (미리보기에 표시, 예배당 화면은 그대로)
3. 미리보기를 확인하고 `F9` (또는 처음부터 `Ctrl+Enter` 로 검색+송출)

### 본문을 순서대로 읽을 때
1. `롬8:18-25` 검색 → `F9` 송출
2. `F6` 다음 슬라이드, `F5` 이전 슬라이드
3. 범위 끝에서는 더 넘어가지 않습니다. 하단 **이동**을 "범위 끝에서 다음 절로"로 바꾸면 계속 이어갑니다(책 끝에서는 멈춤).

### 화면 숨기기
- `F10` : 본문 숨김 ↔ 복원 (숨겨도 본문은 기억하므로 다시 누르면 같은 화면이 나옵니다)

### 보조 화면(예배당 모니터) 출력 끄기
- 하단 **보조 화면** 버튼(또는 `Ctrl+Shift+F`)으로 보조 모니터의 전체 화면 출력을 켜고 끕니다. 켜져 있으면 초록색 "켜짐"으로 표시됩니다.
- 끄면 보조 모니터에서 출력 창이 사라지고, OBS 출력과 프로그램은 그대로 동작합니다. 다시 누르면 같은 모니터로 출력합니다.
- 처음 켤 때는 조작 화면이 아닌 다른 모니터를 자동으로 고릅니다. 다른 모니터로 바꾸려면 설정 → 출력에서 고르세요.

### 프로그램 끄기
- 송출 중에 조작 창의 X 를 누르면 한 번 확인합니다. [종료]를 누르면 출력 창과 OBS 출력까지 모두 꺼집니다.

### 본문 정렬
- 하단 **정렬**에서 예배당 화면의 정렬을 바로 바꿀 수 있습니다: 가운데 · 왼쪽 · **왼쪽 + 내어쓰기** · 오른쪽
- **왼쪽 + 내어쓰기**: 절 번호가 왼쪽 칸에 나오고, 본문은 줄이 바뀌어도 번호 아래로 들어가지 않고 본문 시작 위치에 맞춰 정렬됩니다. 절마다 새 줄에서 시작합니다.
- OBS 자막 등 다른 템플릿은 설정 → 템플릿 → 가로 정렬에서 바꿉니다.

## 4. 검색 방법

### 장절 검색
| 입력 | 결과 |
|---|---|
| `요3:16` · `요한복음 3:16` · `요 3장 16절` | 요한복음 3장 16절 |
| `행5:27-32` | 사도행전 5장 27~32절 |
| `롬 8` | 로마서 8장 전체 |
| `창1:1-2:3` | 창세기 1장 1절 ~ 2장 3절 |
| `롬8:1,28` | 로마서 8장 1절과 28절 |
| `요일4:8` · `요한1서 4:8` | 요한일서 4장 8절 |
| `유 3` | 유다서 3절 (1장뿐인 책은 숫자 하나를 절로 해석) |

- 띄어쓰기는 상관없습니다. `~`, `.`(요3.16)도 인식합니다.
- `요한 3:16` 처럼 여러 책에 해당하면 **후보 목록**이 뜹니다. 임의로 고르지 않습니다.
- 없는 장·절은 "○장은 ○절까지 있습니다"라고 알려 주고 **송출 화면은 그대로** 둡니다.
- 입력하는 동안 아래에 후보가 표시됩니다. `↓`/`↑`로 고르고 `Enter`.

### 본문 단어 검색
- 숫자 없이 입력하면(자동 모드) 본문 검색이 됩니다: `사랑`, `하나님 순종`
- 여러 단어 = 모두 포함한 구절, `"합력하여 선을"` = 구문 검색
- 띄어쓰기 차이는 무시합니다(`세상을이처럼`도 찾음).
- 결과에서 `↓`/`↑` 이동, `Enter` 또는 클릭 → 미리보기, `Ctrl+Enter` → 바로 송출

### 책 목록으로 찾기
- `Ctrl+B` → 책 이름 일부 입력 → `Enter` → 장 번호 버튼(화살표로 이동) → `Enter`

## 5. 슬라이드 자동 분할

하단 **분할**에서 고릅니다.
- **화면에 맞춰 자동**: 화면에 들어가는 만큼 절을 묶습니다.
- **한 절씩 / N절씩**: 지정한 절 수만큼 묶습니다.

어느 방식이든
- 글자가 화면 밖으로 잘리지 않도록 실제 화면 크기로 측정해서 나눕니다.
- 글꼴은 템플릿의 최소 크기 아래로 줄이지 않습니다.
- 한 절이 너무 길면 같은 절 번호로 `로마서 8:18 (1/2)`, `(2/2)` 처럼 나누고 이어지는 부분에 `…`를 표시합니다.
- 예배당 화면과 OBS 자막 **두 디자인 모두에 들어가도록** 나눕니다.
- 미리보기·LIVE 아래에 "다음:" 으로 다음 슬라이드 내용이 보입니다.

## 7. 출력 디자인 (템플릿)

**설정 → 템플릿**에서 편집합니다. 오른쪽에 저장 전 미리보기가 바로 보입니다.

- **배경 이미지**: 빠른 설정·템플릿의 배경 줄에서 **🖼 이미지**를 누르고 그림 파일(png·jpg·webp)을 고르면 됩니다. 글자가 잘 보이도록 '이미지 어둡게', '화면 채우기 / 전체 보이기'를 조절하세요. 테마 배경으로 돌아가려면 맨 앞의 **테마** 견본을 누릅니다.
- **로고**: 로고 줄에서 없음 · 레드 쉴드 · 크레스트 중에 고르거나 **내 로고 올리기…** 로 교회 로고(투명 배경 png 권장, svg 가능)를 올립니다. 위치(↖ ↑ ↗ ↙ ↓ ↘)와 크기를 바꿀 수 있습니다.
- 기본 제공: 일반 예배 · 설교 송출(하단 자막) · 성경 봉독(큰 글씨) · 투명 출력(OBS 자막) · 사용자 설정
- 조정 항목: 해상도(Full HD/4K/사용자 지정), 안전영역, 배경(단색·투명·이미지), 글꼴·크기·최소 크기·자동 맞춤·굵기·색·줄 간격·자간, 정렬, 세로 배치, 상하좌우 여백, 장절 표시 위치·크기·색, 절 번호, 번역본 이름, 단락 표제, 자막 상자, 외곽선, 그림자, 전환 효과(없음/페이드)
- **저장 / 복제 / 새 템플릿 / 삭제**. 출력에서 사용 중인 템플릿은 삭제할 수 없습니다.
- 출력별 템플릿 지정: **설정 → 출력**의 "출력별 템플릿". 예배당은 큰 중앙 본문, OBS 는 하단 두 줄 자막처럼 따로 지정할 수 있습니다.

## 8. 출력 상태 확인

하단 오른쪽에 표시됩니다.
- **예배당 화면**: 초록 = 출력 중, 빨강 = 지정한 모니터가 연결되어 있지 않음(출력 창을 숨김. 다시 연결하면 자동 복구)
- **OBS 전체 / OBS 자막**: 연결된 브라우저 소스 수와 "동기화됨"(출력 화면이 최신 송출 내용을 받았다고 응답) 여부
- 설정 → 출력 아래에 연결별 상세 상태가 있습니다.

## 9. 데이터와 백업

- 데이터 폴더: `%APPDATA%\WorshipCue\data` (설정 → 정보에 표시)
  - `settings.json` 설정(자동 저장, `settings.backup.json` 백업)
  - `bible.db` 성경 데이터베이스(SQLite)
  - `logs\` 송출·오류 기록(30일 보관, 개인정보 없음)
  - `media\` 배경 이미지
- 이 폴더를 복사해 두면 다른 PC로 옮기거나 복구할 수 있습니다.

### 명령줄 가져오기 도구
```
node tools/import.js 성경.json --id krv --name 개역한글 --license "저작재산권 보호기간 만료" --source "받은 곳" --check
```
`--check` 는 검증만 하고 DB를 바꾸지 않습니다. 빼면 가져옵니다.

### 베들레헴 성경(.bdb) 가져오기
1. 베들레헴 성경 설치: https://bethlehembible.org/setup/#윈도우 → 압축을 풀어 `BethlehemWin` 폴더를 `C:\BethlehemWin` 처럼 드라이브 맨 위에 복사
2. 설정 → 성경 데이터 → **[자동으로 찾기]** (다른 위치면 경로 입력 후 [이 폴더에서 찾기])
3. 가져올 번역본 체크 → **[선택한 번역본 가져오기]**

`.bdb` 파일 하나만 고를 수도 있습니다. 명령줄로 한 번에 가져오려면:
```
node tools/import-bethlehem.js "D:\…\베들레헴 성경\BethlehemWin"
```
개역한글·개역개정·쉬운성경·우리말성경·현대인의성경·ESV·NIV(2011)를 가져옵니다.
- 쉬운성경의 `<세계의 시작>` 같은 단락 표제는 본문과 분리합니다(템플릿 "단락 표제 표시"로 화면에 낼 수 있음).
- NIV 의 각주 표시(`*`, `[a]`)와 각주 내용은 본문에서 분리합니다. NIV 에 본문이 없는 절(마 17:21 등 16절)은 제외됩니다.
- 시편 표제 `[다윗의 시]`는 원래 1절 본문이므로 그대로 둡니다.
- 주석(.cdb)·사전(.dct) 파일은 성경 본문이 아니므로 가져오지 않습니다.

### 지원하는 JSON 구조
- `{ "version": {...}, "verses": [{ "book": 1, "chapter": 1, "verse": 1, "text": "..." }] }`
- `[{ "book": "창", "chapter": 1, "verse": 1, "text": "..." }]` (book 은 번호·정식 명칭·약어)
- `[{ "name": "창세기", "chapters": [["1절", "2절", ...], ...] }, ...]` (66권 순서)
- `{ "창세기": { "1": { "1": "..." } } }`

## 10. 문제 해결

| 증상 | 확인 |
|---|---|
| 상단에 "포트 ○○를 다른 프로그램이 사용 중" | 다음 포트로 실행된 상태입니다. OBS 주소를 설정 → 출력에 표시된 주소로 바꾸거나, 그 포트를 쓰는 프로그램을 종료하고 다시 실행하세요. |
| 예배당 화면이 안 나옴 | 설정 → 출력에서 모니터와 "전체 화면 출력 켜기" 확인. Ctrl+Shift+F 로 켜고 끌 수 있습니다. |
| OBS 에 안 나옴 | 하단 상태에 "OBS … 연결 없음"이면 브라우저 소스 URL·포트 확인 |
| 단축키가 안 먹음 | 다른 창에 초점이 있으면 전역 단축키를 켜야 합니다. 설정 → 단축키에서 등록 실패 표시 확인 |
| 글자가 너무 작음 | 템플릿의 최소 글꼴 크기를 올리면 슬라이드가 더 잘게 나뉩니다 |
