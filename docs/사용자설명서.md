# 워십프리젠터 사용자 설명서

워십프리젠터 는 교회 예배 순서(큐시트)를 미리 만들어 두고, 예배 중에는 F6 하나로 성경·찬양 가사·찬송가 악보·광고·영상을 차례대로 예배당 화면과 OBS 방송에 내보내는 프로그램입니다.
**검색·미리보기·편집은 송출 화면을 바꾸지 않습니다.** 송출(F9 · 더블클릭 · Ctrl+Enter)했을 때만 LIVE 화면이 바뀝니다.

> 그림이 있는 짧은 안내는 [README](../README.md#그림으로-보는-사용법) 에 있습니다. OBS 연결은 [OBS 설정 가이드](OBS설정가이드.md).

## 1. 시작하기

1. [Releases](https://github.com/hahadark/WorshipCue/releases/latest) 에서 `WorshipPresenter-…-Portable.exe` 를 받아 실행합니다. 설치가 필요 없고, 처음 실행할 때 잠깐 로딩 화면이 나옵니다.
2. **성경**: 개역한글이 들어 있습니다. 개역개정 등은 베들레헴 성경을 설치한 뒤 `설정 → 성경 데이터 → 자동으로 찾기` ([9장](#9-데이터와-백업)).
3. **예배당 모니터**: 보조 모니터를 연결하고 하단 `보조 화면` (Ctrl+Shift+F). 모니터는 `설정 → 출력` 에서 고릅니다.
4. **OBS**: 브라우저 소스로 연결합니다 → [OBS 설정 가이드](OBS설정가이드.md).
5. **찬송가 PPT**: `🎼 찬송가·PPT → 찬송가 폴더·기본 배경 설정` 에서 폴더 등록 ([3-3](#3-3-찬송가찬양-ppt)). 탐색기에서 폴더를 라이브러리 패널에 끌어다 놓아도 됩니다.
6. **첫 큐시트**: 왼쪽 큐시트의 `⋯ → 새 큐시트`, 또는 `파일 → 주보 순서 붙여 넣기 → 큐시트` ([3-2](#3-2-주보로-큐시트-만들기-ai)).

> 인터넷은 필요 없습니다 (AI 주보·온라인 찬양 찾기만 인터넷 사용). 모든 검색과 출력은 이 PC 안에서 처리됩니다.

| 하단 | 이전·다음·송출 / 지우기 단추 묶음(글자·배경·오버레이·음악·로고·모두), 보조 화면, 출력 연결 상태 |

화면 아래 송출 줄에는 자주 쓰는 단추(이전 · 다음 · 송출 · 글자 숨김 · 모두 지우기 · 보조 화면)만 두고, 배경 지우기 · 오버레이 끄기 · 로고 화면 · 음악 멈춤은 **`지우기 ▾`** 에 모았습니다 (켜진 것이 있으면 단추에 '로고 화면 ▾' 처럼 표시). 큐시트 아래 순서 넣기 단추도 찬송가·성경·찬양·공지·제목만 두고 나머지는 **`＋ 더보기 ▾`** 에 있습니다. 어디서든 **오른쪽 클릭**하면 그 자리에서 쓸 수 있는 기능만 모은 메뉴가 나옵니다.

## 3. 예배 준비: 큐시트 만들기

### 3-1. 순서 넣기 · 바로 고치기

- 왼쪽 큐시트에서 순서를 **클릭**하면 가운데 위쪽 편집칸에 그 순서의 내용이 나옵니다.
- 순서를 클릭·더블클릭해도 **미리보기에만** 나오고 예배당·OBS 화면에는 나가지 않습니다 ('미리보기 끄기' 모드여도). 내보낼 때는 `송출` (F9) · `다음` (F6) · 오른쪽 클릭 `송출`.
- 제목·가사·장절·내용·배경을 고치면 **바로 저장**되고 미리보기도 바로 바뀝니다 (저장 버튼 없음).
- 편집칸의 ▲ ▼ 로 순서 이동, `복제`, `지우기` 를 할 수 있습니다. 끌어서 옮겨도 됩니다.
- 아래 `🎼 찬송가 📖 성경 🎵 찬양 …` 버튼으로 넣은 새 순서는 **지금 고른 순서 바로 다음**에 들어갑니다.

#### 편집칸 보이기·숨기기

- 가운데 위 `✎ 편집칸` 단추(켜져 있으면 파란색), `큐시트 → 편집칸 보이기`, 또는 **Ctrl+Shift+E** 로 켜고 끕니다. 편집칸의 ✕ 를 눌러도 숨겨집니다.
- 숨겨 두면 순서를 클릭해도 미리보기만 바뀌고 편집칸은 열리지 않습니다 (예배 중 화면을 넓게). 고른 상태는 이 PC 에 기억됩니다.
- 숨긴 채로 고치려면 **F2**, 순서 오른쪽의 ✎ 단추, 또는 오른쪽 클릭 → '편집칸에서 고치기' (편집칸이 다시 켜집니다).

#### 오른쪽 클릭 메뉴

어디서든 오른쪽 클릭하면 그곳에서 쓸 수 있는 기능이 나옵니다. 방향키·Enter 로 고르고 Esc 로 닫습니다.

| 곳 | 메뉴 |
|---|---|
| 큐시트 순서 | 미리보기 · 송출 · 편집칸에서 고치기 · 슬라이드 편집 · 제목 바꾸기 · 메모 · 예정 시간 · 찬양 라이브러리에 저장 · 위로·아래로·맨 위로·맨 아래로 · 복제 · 지우기 · **이 다음에 넣기**(찬송가·성경·찬양·공지·제목·이미지·영상·음악·빈 화면) |
| 큐시트 빈 곳 | 순서 넣기 · 주보로 큐시트 만들기 · 큐시트 관리 |
| 슬라이드 격자·목록 | 미리보기 · 바로 송출 · 이 슬라이드 편집 · 이 순서 편집칸 · 목록/격자 바꾸기 |
| 성경 검색 결과 | 미리보기 · 바로 송출 · 이 본문을 큐시트에 넣기 · 장절·본문 복사 |
| 미리보기 화면 | 송출 · 이전/다음 슬라이드 · 이전/다음 순서 · 이 슬라이드 편집 · 미리보기 끄기 |
| LIVE 화면 · 하단 단추줄 | 이전/다음 · 글자 숨김 · 배경 · 오버레이 · 음악 멈춤 · 로고 화면 · 모두 지우기 · 보조 화면 · 무대 화면 창 · 송출 기록 |
| 라이브러리 | 큐시트에 넣기 · 배경 · 전체 배경 · 로고 · 재생 · 고치기 · 켜기/끄기 · 지우기 (그 줄의 기능) |
| 슬라이드 편집기 | 글 고치기 · 복제 · 본문 글 앞/뒤 · 지우기 · 글상자·그림·도형 덧붙이기 · 되돌리기 · 슬라이드 초기화 |
| 글 입력칸 | 되돌리기 · 잘라내기 · 복사 · 붙여넣기 · 모두 선택 |

#### 📋 큐시트 관리

큐시트 위 `📋` 단추 (또는 `파일 → 큐시트 열기·새로 만들기·관리`).

- **찾기**: 이름 · 날짜 · 메모 · 순서 제목. **보기**: 전체 · 📌 고정 · 📄 서식 · 🗑 휴지통. **정렬**: 예배 날짜순 · 최근 고친 순 · 이름순.
- 목록에서 고르면 오른쪽에 **이름 · 예배 날짜(요일) · 메모**와 순서 미리보기가 나오고 바로 고칠 수 있습니다. 두 번 누르면 엽니다.
- **📌 맨 위에 고정**: 자주 여는 큐시트를 목록 맨 위로 (큐시트 고르기 칸에도 📌).
- **📄 서식으로 쓰기**: 주일 낮·수요·새벽 예배처럼 늘 같은 순서를 서식으로 두면, 위쪽 `서식에서…` 로 오늘 날짜의 새 큐시트를 바로 만듭니다.
- **⧉ 다음 주 순서로 복제**: 예배 날짜를 7일 뒤로, 이름 속 날짜(예: 2026-10-18 → 2026-10-25)도 바꿔서 복사합니다. `그대로 복제` 는 날짜 그대로.
- **📋 순서지 복사**: '1. 예배로 부름 — 인도: …' 처럼 글로 복사합니다 (단톡방·문서·주보 확인용).
- **💾 내보내기 · 📂 가져오기**: 파일(.json). 왼쪽에서 여러 개를 골라 한 파일로 내보낼 수 있고, 가져오기도 여러 파일을 한 번에.
- **🗑 휴지통**: 지운 큐시트는 휴지통으로 가서 30일 안에 `되살리기` 할 수 있습니다 (30일이 지나면 저절로 지워짐, `아주 지우기` 도 가능).
- **⏰ 예배 진행 시계** 켜기·끄기도 이 창 위쪽에 있습니다.

### 3-2. 주보로 큐시트 만들기 (AI)

창 위쪽에서 방법을 고릅니다. API 키가 없으면 '채팅 AI로' 가 먼저 열립니다.

#### 채팅 AI로 (키 없이)

이미 쓰는 ChatGPT · Claude · Gemini 같은 채팅 AI 로 만듭니다. 요금·키가 필요 없습니다.

1. (선택) '추가 요청' 에 원하는 것을 적습니다 (예: 오후 예배 순서로).
2. `📋 프롬프트 복사` 를 누르고, `💾 샘플 파일 저장` 으로 `워십프리젠터-큐시트-샘플.json` 을 받습니다.

### 3-4. 찬양: 부를 순서와 바로 가기 키

- 가사에 `[1절]` `[2절]` `[후렴]` 을 한 번씩만 쓰고, 편집칸 **부를 순서**에 `1절 후렴 2절 후렴 후렴` 처럼 적습니다. 아래 이름표 단추를 누르면 순서 끝에 붙습니다. 줄여서 `1 C 2 C C` 도 됩니다. 라이브러리 찬양에도 기본 부를 순서를 저장할 수 있습니다.
- 찬양을 송출 중일 때 키보드 `1`~`9` = 그 절, `C` = 다음 후렴, `B` = 브릿지, `E` = 엔딩. LIVE 아래에 '⌨ 1~9·C·B' 가 보이면 쓸 수 있습니다. 찬양팀이 즉흥으로 후렴을 반복할 때 `C` 만 누르면 됩니다.

#### ✂ PPT 여러 순서로 나누기

광고·설교·축도가 PPT 하나에 다 들어 있을 때, 그 PPT 순서의 편집칸에서 **슬라이드 범위** 에 `5-9` 처럼 쓰면 그 범위만 송출합니다. '여러 순서로 나누기…' 를 누르면 슬라이드를 보며 나눌 수 있습니다: 슬라이드를 누르면 시작, Shift 를 누른 채 누르면 끝 → 이름(광고·설교…) → '범위 더하기' 를 되풀이하고 '나누기' 를 누르면 그 자리에 순서가 여러 개 생깁니다. 슬라이드 이름표는 원래 번호 그대로 보입니다.

#### 📌 무대 화면 고정 (순서표 · 고정 글)

`무대·타이머` 패널의 **무대 화면 고정** 에서 '순서표' 를 누르면 무대 화면(설교자·찬양팀 모니터)에 큐시트 전체 순서가 계속 보이고, 지금 송출 중인 순서가 빨갛게, 다음 순서가 테두리로 표시됩니다. 글을 쓰고 '글 고정' 을 누르면 그 글이 크게 고정됩니다 (예: 결단 찬양은 2절까지). 고정하는 동안 지금 화면은 아래 작은 칸에 보입니다. 자주 쓰는 것은 '프리셋으로 저장' 해 두고, 순서마다 `⚡ 송출할 때 자동으로 → 무대 화면` 에서 고르면 그 순서를 송출할 때 바뀝니다. '지금 화면 (기본)' 을 누르면 풀립니다.

#### ⬆ 새 버전 (바뀐 점 · 건너뛰기)

새 버전이 나오면 아래 상태줄에 '새 버전' 이 보입니다 (예배 중에 창이 저절로 뜨지 않습니다). 누르면 **바뀐 점** 과 함께 '지금 다시 시작해서 설치' · '끌 때 설치 (그대로 두기)' (포터블·맥은 '받기…') · **이번 버전 건너뛰기** 가 나옵니다. 건너뛴 버전은 알리지 않고 설치하지 않으며, 다음 버전이 나오면 다시 알립니다. `설정 → 정보` 에서 건너뛰기를 취소할 수 있습니다.

#### ✅ 연결 점검 (예배 전에 한 번)

`도움말 → 연결 점검` 은 예배당 화면 · OBS · 내부망 출력 · 리모컨 · 카메라 · 성경·찬송가 데이터 · 폴더 · 동기화 · 저장 공간과 **열린 큐시트의 순서마다 파일·가사·장절** 을 확인합니다. '문제'(빨강) → '확인 필요'(노랑) 순서로 위에 보이고, 항목 아래 번호대로 고치면 됩니다. '결과 복사' 는 문의할 때 붙여 넣는 글입니다. `도움말 → 로그 묶음 저장` 은 버전 · 점검 결과 · 설정(열쇠·PIN·AI 키는 가림) · 최근 7일 로그를 다운로드 폴더에 글 파일 하나로 저장합니다 — 문제를 알릴 때 붙여 주세요.

#### ⏱ 글자 자동 숨김

순서 편집칸의 **글자 숨김** 줄에서 정합니다.

- **N 초 뒤 글자만 숨김**: 슬라이드가 나가고 N초가 지나면 글자만 숨깁니다 (배경·로고는 그대로). 숨긴 뒤 F6 을 누르면 다음 슬라이드를 보이며 넘깁니다. 0 이면 끔.
- **처음·끝에서 한 번 더 누르면 숨김**: 마지막 슬라이드에서 F6 (첫 슬라이드에서 F5)을 누르면 먼저 글자만 숨기고, 한 번 더 누르면 다음(이전) 순서로 넘어갑니다. 순서 사이에 빈 화면을 두고 싶을 때. 모든 순서에 켜려면 `설정 → 검색·분할 → 큐시트` 의 '그 전에 한 번은 글자만 숨기기'.

#### 📖 교독문 역할 (인도자 · 회중 · 다같이)

공지 순서의 내용 칸에서 줄 앞에 `인도자:` `회중:` `다같이:` (`사회자:` `성도:` `함께:` 도 됨)를 쓰면, 화면에는 머리말이 빠지고 **회중·다같이 줄은 굵게** 나갑니다. `회중:` 만 한 줄에 쓰면 그 아래 줄들(빈 줄 전까지)이 회중 몫입니다. 편집칸의 '역할 이름도 화면에 보이기' 를 켜면 `회중: …` 처럼 머리말도 보입니다. 머리말이 없는 광고 글은 그대로입니다 (`식사: 친교실` 같은 줄은 바뀌지 않음).

#### ✍ 글 서식 (굵게 · 크기 · 색)

찬양 가사 · 공지 내용 칸 아래의 서식 도구, 또는 단축키로 꾸밉니다. 글을 고른 뒤 누르고, 고르지 않으면 그 줄 전체에 적용됩니다.

| 서식 | 단축키 · 도구 | 글 칸에 보이는 모양 |
|---|---|---|
| 굵게 | **Ctrl+B** · `B` (한 번 더 누르면 해제) | `**환영합니다**` |
| 글자 크기 | Ctrl+Shift+> 크게 · Ctrl+Shift+< 작게 · `크기` 목록 (작게 70% ~ 두 배 200%) | `{크기:160}오늘{/크기}` |
| 글자 색 | 색 점 8개 · 🎨 다른 색 | `{색:#ff6b6b}헌신예배{/색}` |
| 지우기 | `서식 지우기` | |

화면(예배당·OBS)에는 서식으로 보이고, 무대 화면·리모컨·목록에는 표시 없이 글만 나옵니다. 슬라이드 편집기의 글 칸과 화면 위 글 고치기에서도 Ctrl+B 등이 됩니다.

### 3-5. 슬라이드 편집 (FreeShow 방식)

모든 순서(찬양·공지·제목·성경·찬송가·이미지·영상·슬라이드쇼·카메라·빈 화면)의 슬라이드를 하나하나 꾸밉니다. (음악 순서만 빼고)

- 열기: 순서 편집칸 `✏ 슬라이드 편집` · 슬라이드 격자 썸네일의 ✏ 또는 오른쪽 클릭 · 슬라이드 목록 오른쪽 클릭 · `큐시트 → 슬라이드 편집` · **Ctrl+E**
- 왼쪽 목록: 맨 위 **공통**(모든 슬라이드), 그 아래 가사·글 덩어리마다 슬라이드. 따로 꾸민 슬라이드에는 노란 점.
- 가운데 캔버스: 글상자를 끌어 옮기기, 모서리·변의 흰 점으로 크기 조절. 가운데선·가장자리에 붙고(분홍 선), Alt 를 누르면 안 붙습니다. Shift = 비율 유지.
- **더블클릭** 또는 Enter: 화면에서 바로 글 고치기 (Ctrl+Enter 또는 바깥 클릭 = 적용, Esc = 취소). 고친 글은 순서의 가사·공지 내용에 그대로 들어가고, 라이브러리 찬양이면 라이브러리에도 저장됩니다.
- 오른쪽: 글자 크기(넘치면 줄이기), 색·굵게·기울임·그림자, 가로·세로 정렬, 줄 간격, 색 상자(투명도·모서리), 위치·크기(%). '템플릿 위치로' · '꾸미기 초기화'.
- 슬라이드 배경: 그림·영상·색. '본문 글 숨기기' (덧붙인 것만 보이게).
- 덧붙이기: `＋ 글상자` `＋ 그림` `＋ 도형`. '본문 글 뒤로/앞으로', 복제(Ctrl+D), 지우기(Delete).
- '이 꾸미기를 모든 슬라이드에' = 이 슬라이드의 위치·꾸미기를 공통으로. '이 슬라이드 초기화' = 따로 꾸민 것 지우기.
- 위쪽 `예배당 | OBS 자막` 으로 출력별 모양을 보며 고칩니다. OBS 자막(투명 배경)에는 글 내용만 반영되고, 'OBS 자막(투명)에도 위치·꾸미기 적용' 을 켜면 모두 반영됩니다.
- **슬라이드 넘기기: ← → ↑ ↓** (글상자를 눌러 고른 동안은 그 상자를 0.5% 씩 옮김 · Shift = 5% · Esc 로 고름을 풀면 다시 슬라이드 이동) · PageUp/PageDown · Home/End.
- 되돌리기 Ctrl+Z · 다시 Ctrl+Y · 닫기 Esc (상자를 고른 상태면 먼저 고름 풀기) 또는 `완료`. 편집기가 열려 있어도 F5·F6·F9·F10 송출 키는 그대로 됩니다.
- 편집 내용은 큐시트 순서에 저장되므로, 큐시트를 복제하면 함께 복제됩니다. (가사 덩어리를 새로 넣거나 지우면 슬라이드 번호가 바뀌어 꾸민 것이 다른 슬라이드로 갈 수 있습니다.)

**썸네일에서 바로**: 슬라이드 격자의 썸네일에 마우스를 올리면 왼쪽 위에 **＋** (이 다음에 새 슬라이드 → 바로 글 쓰기) · **✕** (지우기, 성경·찬송가·그림 등은 건너뛰기). 오른쪽 클릭 메뉴에도 넣기·복제·지우기가 있습니다.

**슬라이드 넣기·복제·지우기·옮기기** (찬양·공지·제목):

- 왼쪽 목록 맨 아래 `＋ 슬라이드` (또는 Ctrl+Shift+N): 고른 슬라이드 다음에 새 슬라이드가 생기고 바로 글을 씁니다.
- 슬라이드에 마우스를 올리면 ▲ ▼ (옮기기) · ⧉ (복제 — 꾸민 것도 함께) · ✕ (지우기). 오른쪽 클릭 메뉴에도 있습니다.
- 바꾼 것은 가사·공지 글에 그대로 들어갑니다 (빈 줄·`---` 로 나뉜 덩어리). 이름표(`[1절]`)가 붙은 슬라이드를 지우면 이름표는 다음 슬라이드로 넘어가고, 슬라이드마다 꾸민 것도 번호에 맞춰 같이 옮겨집니다.

**성경·찬송가·이미지·영상·슬라이드쇼·카메라·빈 화면 순서**:

- 본문(성경 구절·찬송가 가사·그림)은 그대로 두고 위치·꾸미기·덧붙이기만 합니다. 그림·영상·카메라·빈 화면 슬라이드에는 본문 글상자가 없고, 글상자·그림·도형을 덧붙여 씁니다 (예: 빈 화면 위에 "잠시 기도하겠습니다").
- `＋ 슬라이드`: 고른 슬라이드 다음에 **제목 카드 슬라이드**를 덧붙입니다 (첫 줄 = 제목, 둘째 줄 = 부제). 덧붙인 슬라이드는 ▲ ▼ ⧉ ✕ 로 옮기기·복제·지우기.
- 원래 슬라이드의 ⊘ = **건너뛰기**: 송출 목록에서 빼기만 하고 내용은 그대로 둡니다 (편집기에서는 흐리게 보이고, ↺ 로 되살림).

### 3-6. 파일 끌어다 놓기

탐색기에서 끌어다 놓으면 됩니다 (화면 아래에 어디에 들어가는지 안내가 나옵니다).

- 순서 편집칸: 그림·영상 → 그 순서 배경
- 라이브러리 패널: 폴더 → 지금 탭의 폴더로 등록 (이미지·영상 / 음악 / 찬송가·PPT)

- AI 주보 창: 주보 파일
- 끌어다 놓은 파일은 등록 폴더 밖에 있어도 열립니다 (최근 500개 기억). 파일을 옮기거나 지우면 다시 끌어다 놓으세요.

### 3-8. 🎞 예배 전 화면 (슬라이드쇼)

- `큐시트 → 순서 넣기 → 🎞 슬라이드쇼` (또는 왼쪽 아래 단추). 기본 제목은 '예배 전 화면', 8초마다 넘김·반복.

- **배경 음악**: 편집칸의 '배경 음악'에서 음악을 고르면 송출할 때 반복 재생, 다음 순서를 송출하면 서서히 꺼집니다.

- **예배 전 화면 자동 만들기**: `큐시트 → 순서 넣기 → 예배 전 화면 자동 만들기…` (또는 `더보기`).
  1. **카드 그림 폴더**: 설교쇼츠 편집기에서 묵상카드·카드뉴스 PNG 를 저장한 폴더를 고르면 가장 최근 묶음(이름_01, 이름_02 …)이 골라집니다. 뺄 그림은 체크를 끕니다.
  2. **카드 문장**: 설교쇼츠 편집기 '홈페이지 묶음 보내기' 폴더(기본 `F:\aside\홈페이지보내기`)의 가장 최근 날짜 묶음에서 불러옵니다. 직접 적어도 됩니다.

### 3-9. 자동 넘김 · 송출할 때 자동으로

모든 화면 순서의 편집칸에 있습니다.

- **⚡ 송출할 때 자동으로**를 펼치면:
  - 설교 타이머 N분 시작 · 무대 메시지 보내기(또는 지우기)
  - 로고 화면 켜기/끄기 · 배경 지우기/다시 보이기
  - 오버레이 켜기 · 끄기(하나 또는 모두) · 재생 중인 음악 서서히 멈춤

### 3-10. 찬양팀: 코드 · 두 언어 · 곡 정보 · 그룹 색

- **그룹 색**: 이름표마다 색이 정해져 있습니다 — 절 파랑 · 후렴 빨강 · 브릿지 보라 · 전주·간주 청록 · 엔딩 주황. 미리보기·LIVE 아래 단추, 슬라이드 격자·목록, 무대 화면, 휴대폰 리모컨에 같은 색으로 보입니다.

- **병행 성경**: 상단 '병행' 칸에서 두 번째 번역본을 고르면 성경 본문 절마다 아래에 작게 함께 나갑니다 (번역본이 2개 이상일 때 보임).
- **곡 정보**: 찬양 편집칸의 '곡 정보'(작사·작곡·저작권 번호)와 '보이기'(첫 슬라이드에 · 마지막에 · 처음과 끝에). 화면 아래에 작게 나오고, OBS 자막(투명)에는 나오지 않습니다. 라이브러리 찬양의 '저작권·출처' 가 있으면 그것을 씁니다.

### 4-1. 기본 송출

#### 설교자가 갑자기 다른 구절을 말할 때
1. `Ctrl+K` → 검색창
2. `행5:29` 입력 → `Enter` (미리보기에 표시, 예배당 화면은 그대로)

#### 보조 화면(예배당 모니터) 출력 끄기
- 하단 **보조 화면** 버튼(또는 `Ctrl+Shift+F`)으로 보조 모니터의 전체 화면 출력을 켜고 끕니다. **보조 화면을 끄면 OBS 화면(브라우저 소스)의 슬라이드도 같이 사라지고**, 다시 켜거나 새로 송출하면 다시 나옵니다 (`설정 → 출력` 의 '보조 화면을 끄면 OBS 화면도 숨기기` 로 끌 수 있음). OBS 만 쓰고 보조 화면을 켜지 않는 경우에는 영향이 없습니다. 켜져 있으면 초록색 "켜짐"으로 표시됩니다.
- 보조 화면(예배당 모니터)을 마우스로 클릭하면 그 창이 선택되어 **Esc 로 바로 끌 수 있습니다.** 선택된 상태에서도 F5·F6·F9·F10 송출 키는 그대로 됩니다.
- 끄면 보조 모니터에서 출력 창이 사라지고, OBS 출력과 프로그램은 그대로 동작합니다. 다시 누르면 같은 모니터로 출력합니다.
- 처음 켤 때는 조작 화면이 아닌 다른 모니터를 자동으로 고릅니다. 다른 모니터로 바꾸려면 설정 → 출력에서 고르세요.

#### 프로그램 끄기
- 송출 중에 조작 창의 X 를 누르면 한 번 확인합니다. [종료]를 누르면 출력 창과 OBS 출력까지 모두 꺼집니다.

#### 본문 정렬
- **빠른 설정**(예배당 화면)의 정렬에서 바로 바꿀 수 있습니다: 가운데 · 왼쪽 · **왼쪽 + 내어쓰기** · 오른쪽
- **왼쪽 + 내어쓰기**: 절 번호가 왼쪽 칸에 나오고, 본문은 줄이 바뀌어도 번호 아래로 들어가지 않고 본문 시작 위치에 맞춰 정렬됩니다. 절마다 새 줄에서 시작합니다.
- OBS 자막 등 다른 템플릿은 설정 → 템플릿 → 가로 정렬에서 바꿉니다.

### 4-2. 슬라이드 격자 · 통합 검색

- **`전체 격자` · `전체 목록` (ProPresenter 방식)**: 큐시트의 모든 순서 슬라이드를 순서별 줄로 한 화면에 띄웁니다 (썸네일 또는 글 한 줄씩). 큐시트에서 순서를 누르면 그 줄로 이동하고, 썸네일을 누르면 그 슬라이드가 미리보기에, 두 번 누르면 바로 송출됩니다. 초록 = 미리보기, 빨강 = 송출 중.
- 가운데 위 `목록 | 격자 | 전체 격자 | 전체 목록` 로 바꾸면 슬라이드가 실제 화면 모양 썸네일로 보입니다. 클릭 = 미리보기, 더블클릭 = 송출, 화살표로 이동, 슬라이더로 크기 조절.
- 위 검색창은 성경뿐 아니라 라이브러리의 찬양·찬송가·이미지·영상·음악도 찾습니다. 아래쪽 '라이브러리' 결과를 고르면 큐시트의 고른 순서 다음에 들어갑니다.

### 4-3. 화면 지우기 단추

아래 단추줄: `글자 숨김(F10)` · `배경 지우기`(배경 이미지·영상 숨김) · `오버레이 끄기`(다시 누르면 켜져 있던 것만 다시) · `음악 멈춤`(2.5초 페이드) · `로고 화면`(검은 바탕 가운데 로고) · `모두 지우기`. 켜진 상태의 단추는 노란색입니다.

### 4-4. 무대 화면 · 설교 타이머 · 휴대폰 리모컨

- '무대·타이머' 패널(또는 `송출 → 무대 화면 창 열기`)에서 `🖥 무대 화면 창 열기` → 설교자 모니터로 끌어다 놓습니다. 같은 주소를 이 PC 의 브라우저나 OBS 브라우저 소스로 열어도 됩니다 (다른 PC·태블릿에서는 열리지 않습니다).
- 설교 타이머: 5~40분 단추 또는 직접 입력 → 시작. 일시정지·계속·±1분·지우기. 5분 전에는 노란색, 시간이 지나면 빨간색으로 넘긴 시간(+02:13)을 보여 줍니다.
- 무대 메시지: 글을 쓰고 `보내기`(또는 '5분 남았습니다' 같은 빠른 단추). 무대 화면 위쪽에 깜빡이며 보입니다. `지우기` 로 내립니다.
- **휴대폰 리모컨**: 메뉴 `도구 → 휴대폰 리모컨 ▸ 열기` 에서 켜면 QR 코드·주소·PIN 이 나옵니다. 휴대폰 카메라로 QR 을 찍으면 바로 열립니다. 같은 Wi-Fi 의 휴대폰 브라우저에서 주소를 열고 PIN 을 넣으면 이전·다음·숨김, 절·후렴 바로 가기, 큐시트 순서 송출, 무대 메시지·타이머를 쓸 수 있습니다. 처음 켤 때 Windows 방화벽 창이 뜨면 '개인 네트워크' 를 허용하세요.

## 5. 성경 검색과 슬라이드 나누기

### 장절 검색
| 입력 | 결과 |
|---|---|
| `요3:16` · `요한복음 3:16` · `요 3장 16절` | 요한복음 3장 16절 |
| `행5:27-32` | 사도행전 5장 27~32절 |
| `롬 8` | 로마서 8장 전체 |
| `창1:1-2:3` | 창세기 1장 1절 ~ 2장 3절 |
| `롬8:1,28` | 로마서 8장 1절과 28절 |
| `요일4:8` · `요한1서 4:8` | 요한일서 4장 8절 |
| `유 3` | 유다서 3절 (1장뿐인 책은 숫자 하나를 절로 해석) |

- 띄어쓰기는 상관없습니다. `~`, `.`(요3.16)도 인식합니다.
- `요한 3:16` 처럼 여러 책에 해당하면 **후보 목록**이 뜹니다. 임의로 고르지 않습니다.
- 없는 장·절은 "○장은 ○절까지 있습니다"라고 알려 주고 **송출 화면은 그대로** 둡니다.
- 입력하는 동안 아래에 후보가 표시됩니다. `↓`/`↑`로 고르고 `Enter`.

### 본문 단어 검색
- 숫자 없이 입력하면(자동 모드) 본문 검색이 됩니다: `사랑`, `하나님 순종`
- 여러 단어 = 모두 포함한 구절, `"합력하여 선을"` = 구문 검색
- 띄어쓰기 차이는 무시합니다(`세상을이처럼`도 찾음).
- 결과에서 `↓`/`↑` 이동, `Enter` 또는 클릭 → 미리보기, `Ctrl+Enter` → 바로 송출

### 책 목록으로 찾기
- `Ctrl+B` → 책 이름 일부 입력 → `Enter` → 장 번호 버튼(화살표로 이동) → `Enter`

### 슬라이드 자동 분할

**빠른 설정**의 `분할` 에서 고릅니다.
- **화면에 맞춰 자동**: 화면에 들어가는 만큼 절을 묶습니다.
- **한 절씩 / N절씩**: 지정한 절 수만큼 묶습니다.

어느 방식이든
- 글자가 화면 밖으로 잘리지 않도록 실제 화면 크기로 측정해서 나눕니다.
- 글꼴은 템플릿의 최소 크기 아래로 줄이지 않습니다.
- 한 절이 너무 길면 같은 절 번호로 `로마서 8:18 (1/2)`, `(2/2)` 처럼 나누고 이어지는 부분에 `…`를 표시합니다.
- 예배당 화면과 OBS 자막 **두 디자인 모두에 들어가도록** 나눕니다.
- 미리보기·LIVE 아래에 "다음:" 으로 다음 슬라이드 내용이 보입니다.

## 6. 화면 배치 · 작업공간 · 화면 테마

### 6-1. 패널 배치 바꾸기 · 미리보기 끄기

- 각 패널 위의 **탭을 끌어** 다른 패널의 가장자리(위·아래·왼쪽·오른쪽)에 놓으면 그쪽에 붙고, 가운데에 놓으면 탭으로 합쳐집니다. 경계선을 끌면 크기가 바뀝니다.
- 탭 줄 오른쪽 ⧉ = 떠 있는 창으로 띄우기, ⇲ = 다시 붙이기. 탭의 ✕ = 패널 닫기.
- `보기 → 패널 잠그기 · 기본 배치로…`: 닫은 패널 다시 켜기 · **배치 잠그기**(예배 중 실수 방지) · 기본 배치로 되돌리기. 배치는 자동 저장됩니다.
- 상단 `미리보기 켜짐` 단추를 누르면 **미리보기 끔 · 바로 송출** 이 됩니다. 미리보기 패널이 닫히고, 큐시트 순서·본문·슬라이드를 클릭하면 바로 송출됩니다. 다시 누르면 미리보기 방식으로 돌아갑니다.

### 6-2. 작업공간 (배치 저장·바꾸기)

작업공간은 패널 배치를 이름 붙여 저장해 둔 것입니다. 상황마다 바꿔 씁니다.

| 기본 제공 | 단축키 | 쓰임 |
|---|---|---|
| 기본 | Ctrl+Alt+1 | 큐시트 · 본문/편집 · 빠른 설정·라이브러리 · 미리보기·LIVE |
| 예배 준비 (편집 크게) | Ctrl+Alt+2 | 큐시트·편집칸·라이브러리를 크게, 미리보기·LIVE 는 작게 |
| 예배 중 (송출 크게) | Ctrl+Alt+3 | LIVE·미리보기를 크게, 슬라이드 격자, 아래 무대·타이머 |
| 간단 (큐시트 + LIVE) | Ctrl+Alt+4 | 노트북 등 작은 화면 |

- 바꾸기: 상단 '작업공간' 선택칸, 메뉴 `보기 → 작업공간`, 또는 Ctrl+Alt+숫자.
- 저장: 패널을 원하는 대로 배치 → `보기 → 지금 배치를 새 작업공간으로…` → 이름(예: 수요예배, 찬양팀 연습). 내 작업공간은 Ctrl+Alt+5 부터 차례로.
- 고치기: 작업공간을 연 채로 배치를 바꾼 뒤 `보기 → 작업공간 관리 · 덮어쓰기…` 에서 '지금 배치 저장'. 이름 바꾸기·순서(▲)·지우기도 여기서.
- 기본 제공 작업공간은 덮어쓸 수 없습니다 (덮어쓰기를 누르면 새 작업공간으로 저장).

### 6-3. 화면 테마 · 글자 크기 (조작 화면)

`보기 → 🎨 화면 테마 · 글자 크기` (또는 `설정` 메뉴). 이 조작 화면의 색과 글자 크기만 바뀝니다. 송출 화면(예배당·OBS)의 디자인은 '빠른 설정 → 테마' 에서 따로 고릅니다.

| 테마 | 언제 |
|---|---|
| 어둡게 (기본) | 어두운 방송실. 눈부시지 않게, 글자 대비를 높였습니다 |
| 고대비 | 가장 또렷하게: 검은 바탕·흰 글자·진한 테두리 (시력이 약하거나 화면이 멀 때) |
| 밝게 | 낮 예배·밝은 사무실에서 준비할 때 |
| 따뜻하게 | 푸른 빛을 줄인 갈색. 오래 볼 때 눈이 편합니다 |
| 푸른 밤 | 짙은 남색 바탕 |
| 만나로 | 밝은 회청색 바탕에 흰 카드, 남색 머리 줄 (만나로 스튜디오·설교쇼츠 편집기와 같은 모양). 순서 종류마다 아이콘 색이 다릅니다 |

- 글자 크기: 작게 · 보통 · 크게 · 아주 크게. 단축키 Ctrl+Shift+= (크게) / Ctrl+Shift+- (작게).
- 고른 테마는 설정에 저장되어 다음 실행에도 그대로입니다.

## 7. 출력 디자인과 상태

### 7-1. 출력 디자인 (템플릿)

**설정 → 템플릿**에서 편집합니다. 오른쪽에 저장 전 미리보기가 바로 보입니다.

- **배경 이미지**: 빠른 설정·템플릿의 배경 줄에서 **🖼 이미지**를 누르고 그림 파일(png·jpg·webp)을 고르면 됩니다. 글자가 잘 보이도록 '이미지 어둡게', '화면 채우기 / 전체 보이기'를 조절하세요. 테마 배경으로 돌아가려면 맨 앞의 **테마** 견본을 누릅니다.
- **로고**: 로고 줄에서 없음 · 레드 쉴드 · 크레스트 중에 고르거나 **내 로고 올리기…** 로 교회 로고(투명 배경 png 권장, svg 가능)를 올립니다. 위치(↖ ↑ ↗ ↙ ↓ ↘)와 크기를 바꿀 수 있습니다.
- 기본 제공: 일반 예배 · 설교 송출(하단 자막) · 성경 봉독(큰 글씨) · 투명 출력(OBS 자막) · 사용자 설정
- 조정 항목: 해상도(Full HD/4K/사용자 지정), 안전영역, 배경(단색·투명·이미지), 글꼴·크기·최소 크기·자동 맞춤·굵기·색·줄 간격·자간, 정렬, 세로 배치, 상하좌우 여백, 장절 표시 위치·크기·색, 절 번호, 번역본 이름, 단락 표제, 자막 상자, 외곽선, 그림자, 전환 효과(없음/페이드)
- **저장 / 복제 / 새 템플릿 / 삭제**. 출력에서 사용 중인 템플릿은 삭제할 수 없습니다.
- 출력별 템플릿 지정: **설정 → 출력**의 "출력별 템플릿". 예배당은 큰 중앙 본문, OBS 는 하단 두 줄 자막처럼 따로 지정할 수 있습니다.

### 7-2. 출력 상태 확인

하단 오른쪽에 표시됩니다.
- **예배당 화면**: 초록 = 출력 중, 빨강 = 지정한 모니터가 연결되어 있지 않음(출력 창을 숨김. 다시 연결하면 자동 복구)
- **OBS 전체 / OBS 자막**: 연결된 브라우저 소스 수와 "동기화됨"(출력 화면이 최신 송출 내용을 받았다고 응답) 여부
- 설정 → 출력 아래에 연결별 상세 상태가 있습니다.

### 7-3. 📷 카메라 (FreeShow 방식)

카메라는 **송출 배경 층**으로 씁니다. 슬라이드와 따로 있어서, 가사를 넘기거나 다른 순서로 가도 카메라 화면은 그대로 깔려 있습니다.

1. **라이브러리 → '📷 카메라' 탭** (또는 `도구 → 라이브러리 ▸ 카메라`, `송출 → 카메라·미디어 고르기`): 연결된 웹캠·캡처보드·OBS 가상 카메라가 움직이는 미리보기로 나옵니다. 새로 꽂았으면 '새로 찾기'.
2. **▶ 송출 배경** (또는 카메라를 더블클릭): 그 카메라가 지금 송출 화면의 배경으로 바로 나갑니다. LIVE 화면과 카메라 칸에 빨간 테두리 'LIVE 배경' 이 보입니다.
3. 끄기: 같은 단추(■ 배경 끄기)를 다시 누르거나, 탭 위 '배경 끄기', `송출 → 송출 배경 끄기`, LIVE 오른쪽 클릭. '배경 지우기'(하단 단추)를 누르면 잠깐 숨겼다가 다시 보이게 할 수 있습니다.

그 밖의 쓰는 법:

| 단추 | 하는 일 |
|---|---|
| 순서로 | 📷 카메라 순서를 큐시트에 넣기 — 그 순서를 송출하면 카메라 화면 가득 (맞춤: 화면 채우기 / 전체 보이기) |
| 순서 배경 | 고른 찬양·공지·제목·성경 순서의 배경으로 (그 순서에서만) |
| 전체 배경 | 예배당 화면 템플릿 배경으로 (모든 화면) — 빠른 설정 배경 줄의 `📷 카메라` 와 같음 |
| 슬라이드 편집기 `＋ 카메라` | 슬라이드 안의 카메라 상자 (위치·크기·모서리 둥글게) — 예: 설교자 화면을 오른쪽 위에 작게 |

- 그림·영상도 같은 방식으로: '이미지·영상' 탭의 `▶ 송출 배경`.
- HDMI 카메라(캠코더·미러리스)는 캡처보드(HDMI → USB)로 연결하면 웹캠처럼 나옵니다. OBS 의 '가상 카메라 시작' 을 켜면 'OBS Virtual Camera' 로 OBS 화면을 받을 수도 있습니다.
- 예배당 화면(이 PC 의 출력)과 조작 화면에서 보입니다. OBS 브라우저 소스는 카메라를 열 수 없으므로, OBS 에서는 OBS 의 카메라 소스 위에 'OBS 자막' 을 겹치세요.
- 카메라가 빠지면 그 자리에 '📷 카메라 없음' 이 나옵니다. 다시 꽂고 다시 고르세요.

**⚙ 화질 (카메라마다 세부 설정)** — 카메라 칸의 `⚙ 화질`:

| 항목 | 설명 |
|---|---|
| 해상도 | 자동(1080p 우선) · 720p · 1080p · 1440p · 4K. 칸 아래와 창 위에 **지금 받는 화질**(예: 1920×1080 · 30fps)과 이 카메라의 최대 화질이 나옵니다 |
| 프레임 | 자동(30fps 우선) · 24 · 25 · 30 · 50 · 60fps |
| 꼭 맞추기 | 고른 해상도·프레임을 반드시 쓰기 (카메라가 못 내면 가장 가까운 화질) |
| 좌우 반전 · 밝기 · 대비 · 채도 | 화면에서 바로 바뀝니다 |

- 조작 화면과 예배당 화면 창에 똑같이 적용되고, 프로그램을 다시 켜도 기억합니다.
- 카메라가 내보내는 화질을 줄이거나 늘리지 않고 그대로 받습니다. 화질이 낮게 나오면 `⚙ 화질` 의 '지금 받는 화질' 을 확인하세요.
- 캡처보드는 USB 3.0(파란 단자)에 꽂으세요. USB 2.0 에서는 1080p 가 안 나오거나 프레임이 떨어질 수 있습니다. 카메라 앱·OBS 가 같은 카메라를 쓰고 있으면 화질이 떨어지거나 열리지 않을 수 있습니다.

## 9. 데이터와 백업

- 데이터 폴더: `%APPDATA%\WorshipCue\data` (설정 → 정보에 표시)
  - `settings.json` 설정(자동 저장, `settings.backup.json` 백업)
  - `bible.db` 성경 데이터베이스(SQLite)
  - `logs\` 송출·오류 기록(30일 보관, 개인정보 없음)
  - `media\` 배경 이미지
- 이 폴더를 복사해 두면 다른 PC로 옮기거나 복구할 수 있습니다.

### 명령줄 가져오기 도구
```
node tools/import.js 성경.json --id krv --name 개역한글 --license "저작재산권 보호기간 만료" --source "받은 곳" --check
```
`--check` 는 검증만 하고 DB를 바꾸지 않습니다. 빼면 가져옵니다.

### 베들레헴 성경(.bdb) 가져오기
1. 베들레헴 성경 설치: https://bethlehembible.org/setup/#윈도우 → 압축을 풀어 `BethlehemWin` 폴더를 `C:\BethlehemWin` 처럼 드라이브 맨 위에 복사
2. 설정 → 성경 데이터 → **[자동으로 찾기]** (다른 위치면 경로 입력 후 [이 폴더에서 찾기])
3. 가져올 번역본 체크 → **[선택한 번역본 가져오기]**

`.bdb` 파일 하나만 고를 수도 있습니다. 명령줄로 한 번에 가져오려면:
```
node tools/import-bethlehem.js "D:\…\베들레헴 성경\BethlehemWin"
```
개역한글·개역개정·쉬운성경·우리말성경·현대인의성경·ESV·NIV(2011)를 가져옵니다.
- 쉬운성경의 `<세계의 시작>` 같은 단락 표제는 본문과 분리합니다(템플릿 "단락 표제 표시"로 화면에 낼 수 있음).
- NIV 의 각주 표시(`*`, `[a]`)와 각주 내용은 본문에서 분리합니다. NIV 에 본문이 없는 절(마 17:21 등 16절)은 제외됩니다.
- 시편 표제 `[다윗의 시]`는 원래 1절 본문이므로 그대로 둡니다.
- 주석(.cdb)·사전(.dct) 파일은 성경 본문이 아니므로 가져오지 않습니다.

### 지원하는 JSON 구조
- `{ "version": {...}, "verses": [{ "book": 1, "chapter": 1, "verse": 1, "text": "..." }] }`
- `[{ "book": "창", "chapter": 1, "verse": 1, "text": "..." }]` (book 은 번호·정식 명칭·약어)
- `[{ "name": "창세기", "chapters": [["1절", "2절", ...], ...] }, ...]` (66권 순서)
- `{ "창세기": { "1": { "1": "..." } } }`

## 10. 문제 해결

| 증상 | 확인 |
|---|---|
| 상단에 "포트 ○○를 다른 프로그램이 사용 중" | 다음 포트로 실행된 상태입니다. OBS 주소를 설정 → 출력에 표시된 주소로 바꾸거나, 그 포트를 쓰는 프로그램을 종료하고 다시 실행하세요. |
| 예배당 화면이 안 나옴 | 설정 → 출력에서 모니터와 "전체 화면 출력 켜기" 확인. Ctrl+Shift+F 로 켜고 끌 수 있습니다. |
| OBS 에 안 나옴 | 하단 상태에 "OBS … 연결 없음"이면 브라우저 소스 URL·포트 확인 |
| 단축키가 안 먹음 | 다른 창에 초점이 있으면 전역 단축키를 켜야 합니다. 설정 → 단축키에서 등록 실패 표시 확인 |
| 글자가 너무 작음 | 템플릿의 최소 글꼴 크기를 올리면 슬라이드가 더 잘게 나뉩니다 |
| 휴대폰 리모컨이 안 열림 | 휴대폰이 같은 Wi-Fi 인지, Windows 방화벽에서 워십프리젠터 의 '개인 네트워크' 허용을 확인. 리모컨 창의 주소를 직접 입력해 보세요 |
| 찬송가 PPT 가 그림으로 안 나옴 | '화면 그대로' 방식과 `.pptx` 는 PowerPoint 가 있어야 합니다. 없으면 폴더 읽는 방식을 '자동' 으로 |
| 채팅 AI 가 주보를 못 읽음 | hwp 대신 PDF·사진으로 올리세요. 답에서 큐시트를 못 찾으면 "JSON 코드 블록 하나로 다시 답해 줘" |
| 편집칸이 안 보임 | 가운데 위 `✎ 편집칸` 단추 · F2 · Ctrl+Shift+E (✕ 로 닫으면 숨김 상태로 기억) |
| 화면 배치가 이상함 | `보기 → 패널 잠그기 · 기본 배치로` (또는 Ctrl+Alt+1) |
| 조작 화면 글자가 작음·흐림 | `보기 → 화면 테마` 에서 '고대비' 나 글자 크기 '크게' (Ctrl+Shift+=) |
