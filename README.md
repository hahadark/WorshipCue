# WorshipCue

교회 **예배 순서(큐시트) 통합 송출 프로그램** (Windows)

예배 순서를 미리 만들어 두고 — 성경 · 찬양 가사 · 광고 · 제목 카드 · 이미지 — 예배 중에는 **F6 하나로 차례대로** 예배당 화면(보조 모니터)과 OBS 방송에 띄웁니다.
성경 송출 프로그램 [BibleCast](https://github.com/hahadark/BibleCast)를 바탕으로 만들었습니다.

**⬇ 받기**: [최신 포터블 (설치 없이 실행)](https://github.com/hahadark/WorshipCue/releases/latest) — 개역한글 포함, 다른 번역본은 베들레헴 성경에서 가져오기

![WorshipCue 조작 화면](docs/images/main.png)

<sub>왼쪽: 큐시트(예배 순서·예정 시각) · 가운데: 고른 순서 편집칸과 슬라이드 · 오른쪽: 미리보기(초록)와 LIVE(빨강). 빨간 줄 = 송출 중인 순서, 초록 줄 = 미리보기 중인 순서. (화면의 이름·가사는 모두 예시입니다)</sub>

## 이렇게 씁니다

1. **예배 전**: 큐시트에 순서를 넣습니다 — `🎼 찬송가·PPT` `📖 성경` `🎵 찬양` `📢 공지` `🏷 제목` `🖼 이미지` `🎬 영상` `🔊 음악` `⬛ 빈 화면`
   주보 파일이 있으면 **🤖 AI 로 큐시트를 한 번에** 만들 수 있습니다 (파일 → 주보로 큐시트 만들기).
   순서를 클릭하면 **가운데 편집칸에서 바로 고칠 수 있고**, 입력하는 즉시 자동 저장됩니다.
2. **예배 중**: 첫 순서를 더블클릭(또는 F9)으로 송출 → 이후 **F6** 만 누르면
   찬양 1절 → 후렴 → 대표기도 → 성경 봉독(본문 슬라이드들) → 설교 → … 순서대로 넘어갑니다.
3. 설교 중 갑자기 나온 구절은 위 검색창에서 `요 3 16` → Ctrl+Enter 로 바로 송출 (큐시트는 그대로)

## 그림으로 보는 사용법

### 1. 예배 순서 만들기 (예배 전)

메뉴 `작업공간 → 예배 준비` (Ctrl+Alt+2) 로 바꾸면 편집칸과 라이브러리가 크게 나옵니다.

![예배 준비 작업공간](docs/images/ws-prep.png)

1. 왼쪽 아래 단추(또는 메뉴 `순서 넣기`)로 순서를 넣습니다: 🎼 찬송가·PPT · 📖 성경 · 🎵 찬양 · 📢 공지 · 🏷 제목 · 🖼 이미지 · 🎬 영상 · 🔊 음악 · ⬛ 빈 화면
2. 순서를 클릭하면 가운데 편집칸에서 바로 고칩니다 (입력 즉시 저장). 찬양은 `[1절]` `[후렴]` 을 한 번씩만 쓰고 '부를 순서' 에 `1절 후렴 2절 후렴`.
3. ⏰ 에 예배 시작 시각, 순서마다 예정 시간(분)을 넣으면 순서별 예정 시각과 끝 예정 시각이 보입니다.
4. 자주 쓰는 찬양·배경 그림·영상·음악·오버레이는 **라이브러리** 패널에 모아 두고 더블클릭으로 넣습니다.

| 이미지·영상 | 오버레이 (시계·카운트다운·배너) |
|---|---|
| ![라이브러리 이미지](docs/images/library-images.png) | ![오버레이](docs/images/library-overlays.png) |

**🤖 주보로 한 번에**: 메뉴 `파일 → 주보로 큐시트 만들기`. 주보 파일(hwp·pdf·사진…)을 고르면 AI 가 순서를 만들고 찬송가·장절까지 연결합니다 (오픈라우터 키 필요).

![AI 주보](docs/images/ai.png)

### 2. 예배 진행 (예배 중)

`작업공간 → 예배 중` (Ctrl+Alt+3): LIVE·미리보기가 크고, 가운데에 슬라이드 격자, 아래에 설교 타이머.

![예배 중 작업공간](docs/images/ws-live.png)

- 첫 순서를 **더블클릭**(또는 F9) → 그다음은 **F6** 만 누르면 슬라이드 → 다음 순서로 차례대로 넘어갑니다.
- 찬양 중 `1`~`9` = 그 절, `C` = 후렴, `B` = 브릿지로 바로 갑니다 (찬양팀이 후렴을 반복할 때).
- 아래 단추줄에서 필요한 층만 지웁니다:

![화면 지우기 단추](docs/images/footer.png)

|---|---|
| ![가사](docs/images/out-song.png) | ![성경](docs/images/out-bible.png) |

### 3. 설교자 모니터 · 휴대폰 리모컨

| 무대 화면 (지금·다음 슬라이드, 시계, 타이머, 메시지) | 휴대폰 리모컨 |
|---|---|
| ![무대 화면](docs/images/stage.png) | ![휴대폰](docs/images/remote-phone.png) |

- 무대 화면: `보기 → 무대 화면 창 열기` 를 설교자 모니터로 끌어다 놓거나, 주소 `/outputs/stage` 를 다른 PC·태블릿에서 엽니다.
- 휴대폰 리모컨: 메뉴바 **`리모컨`** → 켜기 → 휴대폰 카메라로 QR 을 찍고 PIN 입력. 켜져 있으면 메뉴에 초록 점이 보입니다.

![리모컨 창](docs/images/remote-dialog.png)

### 4. 슬라이드 편집 (FreeShow 방식)

찬양·공지·제목 순서에서 편집칸의 `✏ 슬라이드 편집` (또는 격자 썸네일의 ✏ · 오른쪽 클릭 · **Ctrl+E**).

![슬라이드 편집기](docs/images/slide-editor.png)

- 글상자를 **끌어 옮기고** 모서리로 크기 조절 (가운데·가장자리에 자동으로 붙음, Alt = 안 붙음, Shift = 비율 유지)
- **더블클릭**하면 화면 위에서 바로 글 고치기 → 가사·공지 글에 그대로 반영 ([1절] 이름표는 그대로)
- 오른쪽에서 글자 크기·색·굵게·정렬·줄 간격·색 상자·그림자, 슬라이드 배경(그림·영상·색)
- `＋ 글상자` `＋ 그림` `＋ 도형`(띠·상자·타원)을 덧붙이고, 본문 글 앞·뒤로 배치
- 맨 위 **공통** = 모든 슬라이드에 적용 (슬라이드에서 따로 바꾼 것이 우선). '이 꾸미기를 모든 슬라이드에' 로 한 번에 맞추기
- Ctrl+Z / Ctrl+Y 되돌리기, Delete 지우기, 방향키 미세 이동, PageUp/Down 슬라이드 넘기기
- OBS 자막(투명) 출력에는 글 내용만 반영하고, 'OBS 자막에도 적용' 을 켜면 위치·꾸미기도 반영

### 5. 파일 끌어다 놓기

탐색기에서 파일을 조작 화면에 끌어다 놓으면 바로 들어갑니다.

| 놓는 곳 | 파일 | 결과 |
|---|---|---|
| 큐시트 (순서 위에 놓으면 그 다음에) | PowerPoint (`.ppt` `.pps` `.pptx` `.ppsx`) | 🎼 찬송가·PPT 순서 (`305 나 같은 죄인….ppt` 처럼 번호로 시작하면 '305장') |
| | 그림 · 영상 · 음악 | 🖼 이미지 · 🎬 영상 · 🔊 음악 순서 |
| | 가사 `.txt` | 🎵 찬양 순서 (빈 줄 = 슬라이드, `[1절]` 이름표) |
| 순서 편집칸 | 그림 · 영상 | 그 순서의 배경 |
| 라이브러리 패널 | 폴더 | 지금 탭(이미지·영상 / 음악 / 찬송가·PPT)의 폴더로 등록 |
| 슬라이드 편집기 | 그림 · 영상 | 놓은 자리에 그림 덧붙이기 |
| AI 주보 창 | 주보 파일 | 그 파일로 큐시트 만들기 |

등록한 폴더 밖의 파일도 끌어다 놓은 것은 열 수 있습니다 (최근 500개 기억).

## 큐시트 만들기 · 예배 진행

- **🤖 주보로 큐시트 만들기 (AI)**: 메뉴 `파일` 또는 큐시트 `⋯`. [오픈라우터](https://openrouter.ai) 키를 한 번 넣으면(이 PC 에만, Windows 보호 기능으로 암호화) 주보 파일(hwp · hwpx · docx · pdf · 사진 · txt)이나 붙여 넣은 글에서 예배 순서를 읽어 큐시트를 만듭니다.
  - 찬송가 번호는 등록한 찬송가 폴더의 PPT 와 자동 연결, 성경 장절은 성경 DB 로 확인합니다. 못 찾은 것은 '확인할 것' 으로 알려 줍니다.
  - 추천 모델: `anthropic/claude-haiku-5.5` (빠르고 쌈, 주보 한 번에 약 $0.001) · PDF·사진 주보는 `google/gemini-3.8-flash` · 복잡한 주보는 `anthropic/claude-sonnet-5.5`
  - 주보 내용은 만들 때만 오픈라우터로 보내집니다. AI 결과이니 송출 전에 한 번 확인하세요.
- **예배 진행 시계**: 큐시트 위 ⏰ 에 예배 시작 시각, 순서 편집칸에 예정 시간(분). 순서마다 예정 시각이 보이고, 송출 중에는 '지금 5번 · 예정 11:12 · 3분 늦음'(빨강)·'이름'(파랑)·'제시간'(초록).
- **찬양 부를 순서**: 가사에는 `[1절]` `[후렴]` 을 한 번씩만 쓰고, '부를 순서' 칸에 `1절 후렴 2절 후렴 후렴`(또는 `1 C 2 C C`). 이름표 단추로 넣을 수 있습니다.
- **찬양 바로 가기 키** (찬양 송출 중): `1`~`9` = 그 절, `C` = 다음 후렴, `B` = 브릿지, `E` = 엔딩, `P` = 전주 (한글 자판 ㅊ·ㅠ·ㄷ·ㅔ 도 됨)
- **슬라이드 격자**: 가운데 위 `목록 | 격자`. 클릭 = 미리보기, 더블클릭·Enter = 송출, 크기 조절. 초록 = 미리보기, 빨강 = 송출 중.
- **통합 검색**: 위 검색창에 `은혜` → 성경 본문 검색과 함께 라이브러리의 찬양·찬송가·이미지·영상·음악이 나오고, 고르면 큐시트에 들어갑니다. `31` = 찬송가 31장.

## 무대 화면 · 리모컨 · 화면 지우기

- **무대 화면** (`/outputs/stage`): 설교자·찬양팀 모니터용. 지금 슬라이드(크게)·다음 슬라이드·순서 이름·시계·설교 타이머·전달 메시지·순서 메모. '무대·타이머' 패널에서 창 열기(또는 주소를 다른 PC·태블릿·OBS 에서 열기), 타이머(5~40분·일시정지·±1분, 5분 전 노랑·지나면 빨강), 빠른 메시지('5분 남았습니다' 등).
- **📱 휴대폰 리모컨**: 메뉴바 `리모컨` 에서 켜면 이 PC 의 주소(예: `http://192.168.0.10:37540/`)·QR 코드·PIN 6자리가 나옵니다. 같은 Wi-Fi 의 휴대폰 브라우저에서 열어 PIN 입력 → 이전·다음·숨김, 1절·후렴 바로 가기, 큐시트 순서 눌러 송출, 무대 메시지·타이머. PIN 을 5번 틀리면 30초 잠깁니다. 처음 켤 때 Windows 방화벽 창이 뜨면 '개인 네트워크' 를 허용하세요.
- **화면 지우기** (아래 단추줄): `글자 숨김(F10)` · `배경 지우기` · `오버레이 끄기`(켜져 있던 것만 다시 켜기) · `음악 멈춤` · `로고 화면`(검은 바탕 가운데 로고) · `모두 지우기`. 켜진 단추는 노란색.

## 라이브러리 (찬양 · 찬송가·PPT · 이미지 · 음악 · 오버레이 · 템플릿)

'라이브러리' 패널(기본: 빠른 설정 옆 탭)에서 자료를 모아 두고 큐시트에 넣습니다. **더블클릭 또는 Enter = 고른 순서 다음에 넣기**, 끌어서 큐시트에 놓아도 됩니다.

| 탭 | 하는 일 |
|---|---|
| 찬양 | 가사를 저장해 두고 매주 검색해서 넣기. 큐시트 순서와 **연결**되어 한 번 고치면 그 찬양을 쓰는 모든 큐시트에 반영. 큐시트의 찬양 순서에서 '📚 라이브러리에 저장' 가능 |
| 찬송가·PPT | 등록한 찬송가·PPT 폴더를 번호·제목으로 찾기 (설정·온라인에서 찾기는 '설정·온라인…') |
| 이미지·영상 | 그림·영상(mp4·webm·mov) 폴더 등록 → 썸네일 목록. 그림을 넣으면 이미지 순서, **영상을 넣으면 🎬 영상 순서**. '배경' = 고른 순서의 배경(영상이면 소리 없이 반복), '전체 배경' = 빠른 설정에서 고른 출력의 템플릿 배경, '로고' = 로고 오버레이 |
| 음악 | 음악 폴더(mp3·wav·m4a·ogg·flac) 등록 → ▶ 바로 재생, 재생 막대(일시정지·위치·볼륨·페이드아웃·이어서 재생). 넣으면 **🔊 음악 순서**: 화면은 그대로 두고 재생, F6 으로 오면 재생하고 다음 화면 순서로 넘어감. '다른 화면을 송출하면 페이드아웃' 선택 |
| 오버레이 | 슬라이드와 따로 출력 위에 겹치는 층: **로고 · 시계 · 카운트다운(예: 11:00 까지 / 5분) · 배너 · 글자**. 켜기/끄기 스위치, 위치 9칸, 크기, 색·상자, 예배당/OBS 따로 |
| 템플릿 | 템플릿 미리보기. 예배당·OBS 에 적용하거나 **고른 순서에만** 적용 (예: 성경 봉독만 큰 글씨) |

**🎬 영상 순서**: 화면 가득 재생합니다. 소리는 예배당 전체화면 창에서만 나고(OBS 소스는 소리 없음), 반복·끝나면(마지막 장면 멈춤 / 화면 숨김 / 다음 순서 송출)을 고릅니다. 송출 중에는 LIVE 아래 막대로 일시정지·처음부터·위치 이동.

**배경 영상**: 템플릿 배경(빠른 설정 → 배경 → 🎞 영상)이나 순서별 배경으로 영상을 쓰면 소리 없이 반복 재생하고, 가사를 넘겨도 영상은 끊기지 않습니다.

큐시트 순서 편집칸에서도 **배경 이미지·영상**과 **이 순서에만 쓸 템플릿**(예배당·OBS 각각)을 고를 수 있습니다.

## 테마

빠른 설정 → `테마` 에서 예배당 화면과 OBS 자막 디자인을 한 쌍으로 바꿉니다.

- **구세군**: 레드 쉴드 · 깃발 · 성결 · 자선냄비 · 크레스트
- **방송 스타일**: 국내 여러 교회 예배 영상의 자막 화면 구성(위치·상자·색 계열)을 참고해 만든 5가지 — 그라데이션 상자 · 상자 없는 가사 · 전체 폭 하단 띠 · 흰 카드 · 가운데 작은 상자. 다른 교회의 로고·글꼴·이름은 들어 있지 않습니다.

## 화면 배치 (독) · 작업공간 · 미리보기 끄기

- 조작 화면의 패널(큐시트·성경 책 / 본문·편집 / 빠른 설정 / 라이브러리 / 무대·타이머 / 미리보기 / LIVE)을 **OBS 독처럼** 탭을 끌어 원하는 곳에 붙이고, 탭으로 합치고, ⧉ 로 띄울 수 있습니다. 경계선을 끌어 크기 조절, 배치는 자동 저장됩니다.
- **작업공간**: 배치를 이름 붙여 저장하고 상단 선택칸·`작업공간` 메뉴·Ctrl+Alt+1~9 로 바꿉니다.
- `작업공간 → 패널 보이기·잠그기` 에서 패널 보이기·숨기기, **배치 잠그기**, 기본 배치로 되돌리기.
- 상단 `미리보기 켜짐` 을 누르면 **미리보기 끔 · 바로 송출** (OBS 스튜디오 모드 끄기와 같음): 미리보기 패널이 사라지고, 클릭한 순서·본문·슬라이드가 바로 송출됩니다. 다시 누르면 원래대로.

## 찬송가·찬양 PPT 폴더

PowerPoint 파일(`.pps` `.ppt` `.pptx` `.ppsx`)로 된 찬송가·교독문·찬양 폴더를 그대로 읽습니다.

1. `🎼 찬송가·PPT` → **찬송가 폴더·기본 배경 설정** → `📁 폴더 고르기…` 로 폴더 등록 (여러 개 가능: 새찬송가, 구세군 찬송가, 교독문 …)
2. 번호(`10`)나 제목(`전능왕`)으로 찾아 **Enter / 더블클릭** → 큐시트에 추가 (창이 열린 채로 여러 곡 연달아 추가 가능)
3. 파일 이름이 `010 전능왕 오셔서.pps` 처럼 번호로 시작하면 번호로 찾을 수 있습니다.

악보 그림(투명)과 배경 그림이 나뉘어 있는 파일은 **배경을 따로 고를 수 있습니다**:

| 배경 | 설명 |
|---|---|
| 원래 배경 | 파일에 들어 있는 배경 그림 |
| 흰 배경 | 악보가 가장 또렷하게 보입니다 |
| 템플릿 배경 | 테마·빠른 설정에서 정한 배경 |
| 다른 이미지… | 원하는 그림 파일 |

기본 배경은 찬송가 설정 창에서, 곡마다의 배경은 가운데 편집칸의 `배경` 에서 바꿉니다.
교독문처럼 글자로 된 파일은 글자를 꺼내 원래 배경 위에 템플릿 글꼴로 띄웁니다.
꺼낸 그림은 `%APPDATA%\WorshipCue\data\hymn-cache` 에 저장되어 다음부터 바로 열립니다.

폴더마다 **읽는 방식**을 고릅니다.

| 읽는 방식 | 설명 |
|---|---|
| 자동 | 악보(투명 그림)와 배경을 나눠 꺼냅니다. 배경 바꾸기 가능. PowerPoint 없어도 됨 |
| 화면 그대로 | PowerPoint 로 슬라이드를 보이는 그대로 그림으로 만듭니다 (PowerPoint 필요). 형식이 제각각인 찬양 PPT 에 알맞습니다 |

`.pptx` 는 PowerPoint 가 있으면 화면 그대로, 없으면 글자와 배경만 꺼냅니다.

### OBS 에는 가사만 (하단 자막)

PPT·찬송가 슬라이드는 출력마다 다르게 보낼 수 있습니다. 예배당 화면은 PPT 그림 그대로, OBS 자막에는 **하단에 가사 글자만** 나갑니다.

- 빠른 설정 → `PPT 슬라이드: 그림 그대로 / 가사만` (투명 배경 템플릿은 기본이 '가사만')
- 가사는 이 순서로 자동으로 찾습니다:
  1. PPT 안의 글자 (PowerPoint 로 '화면 그대로' 읽은 슬라이드)
  2. **새찬송가 가사 DB** — 베들레헴 성경의 `BethlehemWin\새찬송가.hdb` 를 자동으로 찾아, 절·후렴을 악보 슬라이드 수에 맞게 나눕니다 (1절 → 후렴 → 2절 → … → 후렴)
- 순서 편집칸의 `OBS 가사` 에 직접 쓰면 그것을 씁니다 (슬라이드마다 빈 줄로 구분). `자동 가사 넣어 고치기` 로 자동 가사를 불러와 고칠 수 있습니다.

### 온라인에서 찾기 (찬양 PPT)

내 폴더에 없는 곡은 **`🌐 온라인에서 찾기`** 를 누릅니다.

1. 기본 브라우저에서 찬양 PPT 사이트의 검색 결과가 열립니다 (검색 주소는 설정에서 바꿀 수 있습니다, `{q}` = 검색어).
2. 브라우저에서 PPT 를 직접 받습니다 (로그인·비밀번호가 필요한 자료는 사이트 안내에 따라 직접 입력).
3. 20분 동안 다운로드 폴더를 지켜보다가 새 PPT 가 다 받아지면 → `문서\WorshipCue 찬양 PPT` 폴더로 옮기고 → **큐시트의 고른 순서 다음에 자동으로 넣습니다.**
4. 다음부터는 검색만 하면 내 폴더에서 바로 나옵니다.

프로그램이 사이트에서 몰래 자료를 받아 오지는 않습니다. 각 사이트의 이용 조건(예: 교회 안에서만 사용, 변경 금지)을 지켜 주세요.

> 찬송가·악보·찬양 파일은 각 저작권자의 허락 범위 안에서 사용하세요. 프로그램에는 찬송가·찬양 파일이 들어 있지 않습니다.
