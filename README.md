# WorshipCue

교회 **예배 순서(큐시트) 통합 송출 프로그램** (Windows)

예배 순서를 미리 만들어 두고 — 성경 · 찬양 가사 · 광고 · 제목 카드 · 이미지 — 예배 중에는 **F6 하나로 차례대로** 예배당 화면(보조 모니터)과 OBS 방송에 띄웁니다.
성경 송출 프로그램 [BibleCast](https://github.com/hahadark/BibleCast)를 바탕으로 만들었습니다.

![WorshipCue 조작 화면](docs/images/main.png)

<sub>왼쪽: 큐시트(예배 순서) · 가운데: 선택한 순서의 슬라이드와 빠른 설정 · 오른쪽: 미리보기(초록)와 LIVE(빨강). 빨간 줄 = 송출 중인 순서, 초록 줄 = 미리보기 중인 순서</sub>

## 이렇게 씁니다

1. **예배 전**: 큐시트에 순서를 넣습니다 — `📖 성경` `🎵 찬양` `📢 공지` `🏷 제목` `🖼 이미지` `⬛ 빈 화면`
2. **예배 중**: 첫 순서를 더블클릭(또는 F9)으로 송출 → 이후 **F6** 만 누르면
   찬양 1절 → 후렴 → 대표기도 → 성경 봉독(본문 슬라이드들) → 설교 → … 순서대로 넘어갑니다.
3. 설교 중 갑자기 나온 구절은 위 검색창에서 `요 3 16` → Ctrl+Enter 로 바로 송출 (큐시트는 그대로)

## 큐시트 항목

| 종류 | 입력 | 화면 |
|---|---|---|
| 📖 성경 | 장절 (`롬 8:18-25`, `시 23`), 번역본 | 화면에 맞게 자동 분할 |
| 🎵 찬양 | 제목, 가사 | **빈 줄로 슬라이드 구분**, `[1절]` `[후렴]` 줄은 슬라이드 이름 (화면에는 안 나옴) |
| 📢 공지 | 제목, 내용 | `---` 줄로 슬라이드 구분, 제목이 위에 함께 |
| 🏷 제목 | 제목, 부제 | 예: "대표기도 / 홍길동 집사", "설교 / 제목 · 본문" |
| 🖼 이미지 | 그림 파일 | 화면 전체 |
| ⬛ 빈 화면 | 검은 화면 / 배경·로고만 | |

- 순서마다 **조작자 메모**(예: "설교 후 바로 광고")를 달 수 있습니다.
- 끌어서(또는 Alt+↑↓) 순서 바꾸기, F2 편집, Delete 삭제
- 큐시트는 여러 개 저장 · **복제(다음 주 순서 만들기)** · 파일로 내보내기/가져오기

## 단축키

| 키 | 기능 |
|---|---|
| F6 / F5 | 다음 / 이전 슬라이드 — 순서의 끝이면 **다음 순서로** |
| F9 · 더블클릭 | 송출 |
| Ctrl+↓ / Ctrl+↑ | 다음 / 이전 순서 미리보기 (송출은 그대로) |
| F2 | 선택한 순서 편집 |
| F10 | 출력 숨김·복원 |
| Esc | 보조 화면 끄기 |
| Ctrl+K · Enter · Ctrl+Enter | 즉석 성경 검색 · 미리보기 · 바로 송출 |

모든 단축키는 설정에서 바꿀 수 있습니다. 자동으로 다음 순서로 넘어가는 기능은 `설정 → 검색·분할 → 큐시트` 에서 끌 수 있습니다.

## BibleCast 에서 이어받은 기능

- 장절·본문 검색, 미리보기/LIVE 분리, 자동 슬라이드 분할, Shift 범위 지정
- 예배당 보조 모니터 + OBS 브라우저 소스 (`http://127.0.0.1:37528/outputs/main` · `/overlay`)
- 구세군 테마, 빠른 설정(글꼴·크기·색·위치·내어쓰기·배경 이미지·로고), 장절 고정
- 베들레헴 성경 자동 가져오기, EPUB 주석서 보기

BibleCast 와 **동시에 실행할 수 있도록** 데이터 폴더(`%APPDATA%\WorshipCue`)와 포트(37528)를 따로 씁니다.

## 성경 데이터

기본은 **개역한글**입니다. 개역개정 등은 [베들레헴 성경](https://bethlehembible.org/setup/#%EC%9C%88%EB%8F%84%EC%9A%B0)을 설치한 뒤
**설정 → 성경 데이터 → 자동으로 찾기** 로 가져오세요. (자세한 방법: [BibleCast README](https://github.com/hahadark/BibleCast#성경-데이터-설치))

찬양 가사는 각 곡의 저작권자 이용 조건(교회 저작권 라이선스 등)을 확인하고 입력하세요.

## 개발

```
npm install
npm start          # 실행
npm test           # 자동 테스트
npm run dist       # Windows 설치판·휴대판 (dist/)
```

| 모듈 | 파일 |
|---|---|
| 큐시트 저장·검증 | `src/core/cues.js` · `db.js` (Cuesheets 표) |
| 큐시트 화면 | `src/web/control/cue.js` |
| 가사·공지 슬라이드 | `src/web/shared/slides.js` (`buildText`) |
| 항목 종류별 표시 | `src/web/shared/render.js` (text · title · image · blank) |

외부 연동 명령: `POST http://127.0.0.1:37528/api/command` (헤더 `X-WorshipCue: 1`) — `listCues`, `getCue`, `saveCue`, `nextSlide`, `toggleLive` …

## 알림

- 구세군 레드 쉴드·크레스트 로고는 구세군(The Salvation Army)의 상표이며, 구세군 교회·기관의 예배 송출용으로 포함했습니다.
- 성경 본문(개역한글 제외)·주석서·찬양 가사는 포함되어 있지 않습니다.
